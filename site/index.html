01Try the online demo体验在线 DemoOpen in your browser and start sharing在浏览器打开，直接体验屏幕共享
  1. Open the demo on a computer.在电脑上打开演示站。

    Visit demo.piik.tv in a desktop browser that supports screen sharing. 用支持屏幕共享的电脑浏览器打开 demo.piik.tv。

  2. Share a screen and copy its invitation.分享画面，复制邀请。

    Select Start sharing, choose a window, then select Copy invite link.点击开始分享，选择一个窗口，再点击复制邀请链接。

  3. Open the invitation on a second device.用另一台设备打开邀请。

    Use a phone or another computer, or invite a friend. Select Play if the browser does not start playback.使用手机、另一台电脑，或邀请朋友加入。如果没有自动播放，点击播放。

  4. Finish the demonstration.结束体验。

    Try the volume and fullscreen controls, then select Stop sharing on the host’s page.试用音量、全屏等播放功能，完成后在房主页面点击停止分享。

About this demo演示站说明

This demo uses direct device-to-device connections (P2P), with media forwarding disabled. Restrictive networks may open the page but block the video.演示站仅使用设备间直连（P2P），未启用媒体转发。 在受限网络下，可能出现页面能打开、画面无法连接的情况。

Self-hosted Piik sites can enable media forwarding (SFU) as a fallback when a direct connection cannot be established.自行部署的 Piik 站点可以启用媒体转发（SFU），为直连失败提供兜底。

02Share with Piik App用客户端分享Download, open and create a room下载后直接开房间
  1. Download and extract Piik App.下载并解压 Piik App。

    Download the App package for your system, extract it completely and keep the folder intact.下载对应系统的客户端程序包，完整解压并保留目录结构。

    Windows
    Open 打开 piik-app.exe
    macOS
    Open 打开 Piik App.app
    Linux
    Run 运行 ./piik-app
  2. Choose Public invite, then Open Piik.选择「公网邀请」，点击「进入 Piik」。

    The launcher opens in your system browser. Public invite creates a temporary Internet address for friends outside your network. If you are on the same network or already have a site, see the mode descriptions.启动页会在系统浏览器里打开。「公网邀请」会生成临时公网地址，方便不在同一网络的朋友加入。如果朋友和你在同一局域网，或你们已有站点，可查看模式说明。

  3. Start sharing and choose a source.点击「开始分享」，选择来源。

    Choose Browser, Apps / Windows or Screens where available. Select the picture and audio you want to share.按可用选项选择浏览器、程序 / 窗口或屏幕，再选择具体画面和声音。

  4. Copy the invitation and keep the App open.复制邀请，并保持 App 运行。

    Check the preview and select Copy invite link. Keep both the App and sharing tab open until you finish.确认预览后点击复制邀请链接。分享期间保持 App 和分享标签页打开，结束时点击停止分享。

Which mode should I use?模式怎么选？

Local room本地房间
Friends are on the same local network and can reach your computer.朋友和你在同一局域网，且能访问你的电脑。
Public invite公网邀请
Create a temporary Internet invitation. Closing the App ends this room and invitation.生成临时公网邀请。退出 App 后，本次房间和邀请结束。
Connect to Site连接站点
Enter the Piik site address your group already uses.输入你们已有的 Piik 站点地址。

Public invite relies on P2P media connections, without a media-server fallback. Some networks may open the page but fail to receive video.公网邀请依赖 P2P 媒体连接，不提供媒体服务器转发兜底；部分网络可能出现网页能打开、画面无法连接的情况。

The macOS and Linux apps have not yet been tested on physical devices. Test reports are welcome on GitHub Issues. On macOS, native capture requires Apple silicon and macOS 13+. On Linux, it needs additional system components. Browser capture is also available.macOS 和 Linux 客户端尚未经过实机测试，欢迎有设备的朋友试用并在 GitHub Issues 反馈。 macOS 原生采集需要 Apple 芯片和 macOS 13 及以上；Linux 原生采集需要额外系统组件。也可以用浏览器采集。

03Browser & self-hosting · Advanced网页版与自建站点 · 进阶Requires an existing site running Piik Server需要一个已部署 Piik Server 的站点
  1. Open the site on a computer.在电脑上打开站点。

    Use the Piik address provided by your friend or administrator. Enter the site passphrase if required.使用朋友或管理员提供的 Piik 地址。如果站点设置了口令，先输入口令。

  2. Choose Start sharing.点击「开始分享」。

    Select a screen, window or tab in the browser’s capture dialog. Enable audio if the selected source supports it, then confirm.在浏览器弹窗中选择屏幕、窗口或标签页；如需声音，勾选可用的音频选项，然后确认分享。

  3. Check the preview and invite a friend.确认预览，发送邀请。

    Check the picture, then select Copy invite link. Send that link to the friends you want to invite.确认画面无误后，点击复制邀请链接，将链接发给要邀请的朋友。

  4. Keep the sharing tab open.分享期间保持标签页打开。

    Use Switch source to change the picture, Pause sharing for a break, and Stop sharing to finish.更换画面时点击切换来源，暂时中断时点击暂停分享，结束时点击停止分享。

Where does the site come from?Piik 站点从哪里来？

Use a site provided by a friend or administrator. Hosting your own is an advanced option: run Piik Server, configure HTTPS and open the required network ports. Follow the self-hosting guide.可以直接使用朋友或管理员提供的站点。自己部署属于进阶操作，需要运行 Piik Server、配置 HTTPS 并开放相应网络端口， 具体步骤见部署指南。

Share from a desktop browser on an HTTPS site. Sources and audio options vary by browser and operating system. No site yet? Start with the demo or App.请用支持屏幕共享的电脑浏览器访问 HTTPS 站点。可分享的画面和声音取决于浏览器及系统。还没有站点时，可以先用在线 Demo 或客户端。

Here to watch a friend?来围观朋友的分享？

  1. Open your friend’s invitation in a phone or computer browser.用手机或电脑浏览器打开朋友发来的邀请链接。
  2. Wait for the picture. If playback does not start, select Play.等待画面出现；如果没有自动播放，点击播放。
  3. Move the pointer over the video or tap it to show volume, fullscreen and other playback controls.将鼠标移到画面上，或轻点画面，显示音量、全屏等播放控件。

Only have a room code? Select Join a room on the same Piik site and enter the four-digit code. Access depends on the host’s settings; a site passphrase or room password may be required.只有房间号时，在同一个 Piik 站点选择加入房间，输入四位房间号。能否加入由房主设置决定，可能需要站点口令或房间密码。

FAQ常见问题

Good to know.你可能
还想知道。

Do I need my own server?需要自己搭服务器吗？

No. Try the online demo, or choose Public invite in Piik App to create a temporary room. You can also use a Piik site provided by someone else. For a permanent site under your own domain, follow the self-hosting guide. 不需要。可以直接体验在线 Demo，或在 Piik App 中选择公网邀请创建临时房间，也可以使用别人提供的 Piik 站点。想用自己的域名长期运行一个站点，再看部署指南。

Does everyone need Piik App?每个人都需要安装 Piik App 吗？

No. Friends watch in a desktop or mobile browser without installing anything. You can host from a supported desktop browser on an existing Piik site, or use Piik App to create a room.不需要。观众用电脑或手机浏览器就能看，无须安装。房主可以在已有 Piik 站点上，用支持屏幕共享的电脑浏览器开始分享，也可以通过 Piik App 创建房间。

How many friends can join?最多能叫多少朋友？

One host and up to 20 invited viewers fit in a room. Piik is made for a private group hanging out around one screen.一个房间支持一位房主和最多 20 位受邀观众。叫上熟悉的朋友，看看游戏、演示作品，或者围观彼此的新发现。

Can I share sound too?声音也能一起分享吗？

Yes, when the selected source and capture method support audio. Check the sound option when choosing what to share. Browser and operating-system support varies; viewers may need to press Play and turn on the video’s sound.可以，前提是选择的画面来源和采集方式支持声音。选择分享内容时，检查声音选项。浏览器和系统支持有所不同；观众可能需要先点播放，再打开视频声音。

Can we watch from different places?不在同一个地方，也能一起看吗？

Yes. Use the demo, an Internet-accessible Piik site, or Public invite in the App. Public invite gives your room a temporary address that can change or become unavailable; closing the App ends the room. The demo and Public invite use direct media connections without server forwarding, so some networks may load the page but block the video. You can also use a Piik site with media forwarding enabled for a fallback connection.可以使用在线 Demo、能从外网访问的 Piik 站点，或客户端的“公网邀请”。公网邀请的地址是临时的，可能中断或变化，退出 App 后房间也会结束。 Demo 和公网邀请的画面靠设备间直连传输，没有服务器转发兜底；部分网络可能出现页面能打开、画面连不上的情况。 也可以使用已启用媒体转发兜底的 Piik 站点。

Which platforms are ready?目前支持哪些平台？

Windows App and browser sharing are the primary tested paths. Viewers can use a computer or phone browser. The macOS and Linux apps have not yet been tested on physical devices; if you have a device, we'd welcome your test results and feedback.目前主要测试 Windows 客户端和浏览器分享，观众可使用电脑或手机浏览器。 macOS 和 Linux 客户端尚未经过实机测试，欢迎有设备的朋友试用并反馈问题。
