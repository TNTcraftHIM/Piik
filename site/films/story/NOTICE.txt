Offline preview inputs: assets/story.mp3, display.woff2 and Anton are local.
To edit the soundtrack, run node site/films/story/sound.mjs with FFmpeg on PATH
or FFMPEG set to its executable. The full Funky Chunk source is cached in
ignored build/films/story/funky-chunk-source.mp3; the script downloads it from
https://incompetech.com/music/royalty-free/mp3-royaltyfree/Funky%20Chunk.mp3
when absent. It writes the finished mix to assets/story.mp3.
