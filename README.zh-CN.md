# Piik

[English](./README.md) · 简体中文

**开一局，朋友坐前排。**

分享你的屏幕，叫上朋友一起看。

Piik 是一个私密游戏屏幕分享工具，最多可邀请 20 位好友一起看。
你来玩，朋友用电脑或手机浏览器观看，无须安装。

<img src="./site/assets/living-room.svg" width="720" height="472" alt="一位玩家分享游戏，三位朋友坐上沙发一起观看。">

## 收到邀请了？坐下就看。

1. 打开朋友发来的邀请链接。
2. 按需点击 **播放**，打开声音，再切到全屏。

只有房间号？打开你们使用的 Piik 站点，选择 **加入房间**。
站点和房间可能需要密码。

## 用浏览器分享

1. 打开你们使用的 Piik 站点，按提示输入站点口令。
2. 点击 **开始分享**，选择屏幕、窗口或标签页；有声音选项时，记得打开。
3. 复制房间的邀请链接，发给朋友。分享期间保持标签页打开。

Piik 首次打开是图示模式，点击顶部的 **中** 即可显示这里用到的按钮文字。
可选画面和声音取决于浏览器与操作系统。

## 用 Piik App 自己开房

Piik App 是一个自带运行组件的程序包，打开后在浏览器里操作分享。

1. 完整解压对应平台的程序包，保留可执行文件旁的 `runtime` 文件夹。
2. Windows 打开 `piik-app.exe`，macOS 打开 `Piik App.app`，Linux 运行 `./piik-app`。
3. 选择 **本地房间**、**公网邀请** 或 **连接站点**，开始分享，再发出邀请。

分享期间保持 App 和分享标签页打开。本地房间适合同一局域网；
公网邀请会生成临时互联网链接。[看看该选哪种模式 →](./docs/guide/getting-started.zh-CN.md#选择-app-模式)
