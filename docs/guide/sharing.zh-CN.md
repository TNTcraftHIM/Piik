# 分享与播放

本页适用于 3.0 内测版；正式版请看 [2.6.1 指南](https://github.com/TNTcraftHIM/Piik/blob/v2.6.1/docs/guide/sharing.zh-CN.md)。

[English](./sharing.md) · 简体中文 · [文档中心](./README.zh-CN.md)

打开站点或创建房间，请先看[快速上手](./getting-started.zh-CN.md)。
获准进入房间的人都可以分享，多个人可同时开播，再各自选择想看的画面。

## 开始分享或切换来源

1. 选择房间，点击房间顶部的 **开始分享**。
2. 按可用选项选择 **浏览器**、**摄像头** 或 App 的窗口／屏幕，再选择具体来源与声音。
   App 选源器可能提示你到 App 中完成选择。
3. 确认本机预览。朋友会在 **正在分享** 列表看到你的画面，点击 **观看** 即可接收。

iPhone／iPad 分享屏幕需使用 iOS／iPadOS 27 及以上的 Safari；观看和摄像头分享不受此屏幕分享门槛限制。
Safari 的屏幕采集不包含系统声音，参阅[浏览器兼容记录](https://github.com/mdn/browser-compat-data/pull/30732)。

![选源器中的示例应用窗口与来源声音开关。](../assets/guide/channel-source.zh-CN.png#gh-light-mode-only)
![选源器中的示例应用窗口与来源声音开关。](../assets/guide/channel-source.zh-CN.dark.png#gh-dark-mode-only)

在自己的画面卡片上点 **切换来源** 替换这一路分享。也可以到另一个房间继续分享，不必先结束原来的分享。
切换侧栏里的房间不会停止已有分享、正在观看的画面或已加入的语音。

普通访问可发送站点地址或公开房间链接。私密房间使用自己的邀请或密码，私密邀请只发给你想邀请的人。
每位房主管理自己房间的访问方式与邀请重置，见[快速上手](./getting-started.zh-CN.md)。

## 分享设置

开播前，从 **开始分享** 旁打开 **分享设置 → 画面**；开播后，入口移到对应画面卡片上，浏览其他房间时仍可调整这一路。
先选画质预设；需要指定分辨率、帧率或码率时，再展开 **画面细调**。
视频编码在开始分享前选择，可用编码取决于浏览器或连接的 App。

![分享设置提供常用预设，详细画面参数可单独展开。](../assets/guide/channel-quality.zh-CN.png#gh-light-mode-only)
![分享设置提供常用预设，详细画面参数可单独展开。](../assets/guide/channel-quality.zh-CN.dark.png#gh-dark-mode-only)

- **分辨率** 表示上限，竖屏和超宽屏仍保留来源比例。
- **滑块** 提供常用值，也可在输入框内填写其他允许值；**返回常用范围** 可回到滑块范围。
- **声音** 包含来源音频质量；分享期间还可调整分享麦克风。

Piik 会根据来源、设备与连接，在这些上限内调整画面。
平台支持情况见 [Native 使用说明](../../prototype/channel-native/README.md)（英文）。

### 给分享起个名字

分享默认使用所选来源的名称。在这一路的 **分享设置** 中展开 **分享标题**，输入名称并 **保存**。
切换来源会保留你的标题；清空输入框再保存，即可恢复使用当前来源的名称。

### 分享麦克风

分享期间，在 **分享设置 → 声音** 中开启 **分享麦克风**，把你的讲解加入画面，
并在这里选择输入设备、音量和语音处理。每次新分享默认关闭，停止该分享时结束。

观看者通过画面声音收听，不必加入语音。[房间语音](./room-tools.zh-CN.md#房间语音)独立运行，
同时开启两路可能让朋友听到两次你的声音，保留需要的一路即可。

## 摄像头与虚拟音频输入

在 **摄像头** 中允许访问画面后，点击对应的预览卡片。分享一台摄像头时，其他摄像头只显示名称。
摄像头自带的麦克风仍需单独选择，用作分享麦克风或房间语音输入。

OBS 虚拟摄像头提供画面；需要带上 OBS 声音时，按
[OBS 音频转接教程](https://obsproject.com/kb/video-call-streaming-tutorial/)设置音频输入，
再在 **分享设置 → 声音 → 分享麦克风** 中选择该音频输入，声音就会随画面传给观看者。
播放音乐或已处理的虚拟音频时，可关闭这里的语音处理。

## 分享屏幕时排除语音软件的声音

连接的 Windows App 提供排除功能时，**屏幕 → 系统声音** 可排除指定应用及其子进程。
**程序 / 窗口** 则在支持时采集所选应用的声音。

1. 在 **屏幕** 中开启 **系统声音**。
2. 在 **排除应用声音** 中选择语音软件的窗口；没有列出时，先打开该窗口，再刷新列表。
3. 选择要分享的屏幕。支持的开播后调整仍位于 **分享设置 → 声音**。

其他应用或混音软件仍可能带上这些声音。关闭 Piik 麦克风后仍能听到自己的声音时，
可暂时关闭来源声音对照，检查混音软件的播放输出或监听。
排除不可用时，可只分享目标应用的声音，或为语音软件选择另一播放设备。

## 播放控制

### 观看与排列画面

在别人的分享旁点击 **观看**。可以同时看多个画面，也可以保留来自不同房间的画面。
点击画面卡片或 **聚焦** 可放大其中一个；选择 **平铺画面** 或 **返回平铺** 再看其他画面。

每路分享的眼睛图标旁显示正在观看的人数，点击可查看名单；分享者和观众都能查看。

鼠标移到画面上，或轻点画面，即可显示播放栏。

| 控件 | 作用范围 |
| --- | --- |
| 播放／暂停 | 只改变自己的本地播放。 |
| 音量 | 观看别人的画面时只调整自己收听；自己的预览中调整的是传给观看者的来源声音，本机预览保持静音。 |
| 播放设置 | 调整本机的画面适配、旋转和弹幕外观。 |
| 剧场模式 | 在当前标签页内展开聚焦的画面。 |
| 悬浮小窗／全屏观看 | 使用浏览器支持的视频小窗或全屏模式。 |
| 房间小窗 | 将人物、聊天与语音控件放在画面旁，见[房间工具](./room-tools.zh-CN.md#把房间放在画面或游戏旁)。 |

## 结束一项活动

- **停止观看** 只关掉你正在看的那一路，不停止来源或其他画面。
- 在自己的画面卡片上点 **暂停分享**，暂停朋友看到的这一路；**继续分享** 可恢复。
- **停止分享** 结束该来源及其分享麦克风，不结束房间聊天或已加入的语音。

语音需单独点击 **退出语音**。保留当前活动需要的 App 和网页；
Browser 与 App 托管房间的区别见[快速上手](./getting-started.zh-CN.md)。
