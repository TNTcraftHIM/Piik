# 分享与播放

[English](./sharing.md) · 简体中文 · [文档中心](./README.zh-CN.md)

第一次使用请先看[快速上手](./getting-started.zh-CN.md)。本页介绍分享的画面、来源声音，
以及只影响自己观看的播放控制。

## 画面与声音设置

1. 在画面下方打开 **分享设置 → 画面**。
2. 先选画质预设；需要指定分辨率、帧率、码率、画面偏好或视频编码时，再展开 **画面细调**。
3. 切到 **声音**，选择来源声音和输出质量。

![分享设置的画面页签：上方是画质预设，下方可展开画面细调。](../assets/guide/sharing-settings.zh-CN.png#gh-light-mode-only)
![分享设置的画面页签：上方是画质预设，下方可展开画面细调。](../assets/guide/sharing-settings.zh-CN.dark.png#gh-dark-mode-only)

*使用示例设置的实际控件。先选预设，只展开需要调整的部分。*

| 设置 | 怎么理解 |
| --- | --- |
| 分辨率 | 表示上限；竖屏和超宽屏仍保留来源比例。 |
| 滑块与自定义数值 | 滑块提供常用值，也可在输入框允许的范围内自定义；**返回常用范围** 可回到附近档位。 |
| 画面与声音质量 | 仍会根据来源、设备和可用带宽调整。 |

已应用的设置会保存在当前站点；通过新版 App 打开时，更换公网邀请网址也能保留分享画质设置。

## 摄像头与虚拟音频输入

画面声音与说话声分别控制，静音其中一个不会静音另一个。

![来源声音随分享画面传输，使用播放音量；麦克风通过房间语音传输，使用语音收听控件。](../assets/guide/audio-paths.zh-CN.svg)

摄像头分享只请求画面权限。在 **摄像头** 页签中允许访问后，点击对应的画面卡片开始分享。
设备名称和可用预览取决于浏览器权限；正在分享摄像头时，其他摄像头只显示名称。
带麦克风的摄像头仍需分别选择画面和音频输入。OBS 虚拟摄像头只提供画面；
如需带上 OBS 的声音，可按 [OBS 音频转接教程](https://obsproject.com/kb/video-call-streaming-tutorial/)
设置虚拟音频设备，再在[房间语音的麦克风设置](./room-tools.zh-CN.md#房间语音) 中选择对应输入并开启麦克风。
它使用实时语音频道，与摄像头画面、来源声音分开传输。

## 分享屏幕时排除语音软件的声音

在 Windows 上，此控件用于 **屏幕** 分享的系统声音。**程序 / 窗口** 只采集所选应用及其子进程的声音；
**摄像头** 分享画面，麦克风或虚拟音频输入通过房间语音单独传输。

在支持此功能的 Windows App 中，打开 **屏幕** 页签并开启 **系统声音**，
在 **排除应用声音** 中选择语音软件的窗口，再选择要分享的屏幕。
未列出的应用请先打开窗口，再刷新。此功能排除所选进程及其子进程，
其他应用的声音仍会被分享，包括输出到其他播放设备的声音。
它不影响 Piik 麦克风，也不能消除扬声器被麦克风收音产生的回声。

使用虚拟麦克风时，如果关闭 Piik 麦克风后仍能听到你的声音，可暂时关闭 **系统声音** 对照。
若声音随之消失，请检查混音软件的播放输出与监听，或改为只分享目标应用的窗口音频。
排除语音软件不会同时排除另一个混音软件；后者输出到虚拟播放设备的声音也可能被采集。

开播后，可在 **分享设置 → 声音** 中调整系统声音和排除的应用，无需停止分享。
所选应用关闭或重启后，来源声音会停止；请刷新应用列表并重新选择。
暂时关闭来源声音会保留排除选择；需要恢复完整的系统声音时，选择 **不排除**。
此控件需要新版页面和通过进程排除能力检测的 Windows App，不适用于浏览器自带的分享选择器。
Windows 10 是否支持取决于系统更新与实际检测；未显示此选项时，可改为分享单个应用窗口，或将语音软件输出到另一播放设备。

## 播放控制

将鼠标移到画面上，或轻点画面，即可显示播放控制栏。

| 你想做什么 | 用哪个控件 | 影响谁 |
| --- | --- | --- |
| 暂停观看或静音来源声音 | 画面上的播放控制栏 | 只影响自己；房主的预览默认静音。 |
| 暂停朋友看到的画面 | 画面下方的 **暂停分享** | 所有观众。 |
| 关闭麦克风或暂停收听说话声 | **互动 → 语音** | 自己的语音控制，与画面声音分开。 |

<div class="guide-control-reference">

| 按钮 | 作用 |
| --- | --- |
| **音量** | 支持增强时最高 200%，否则最高 100%；声音失真时调低一些。 |
| **画面适配** | 点击切换：**完整显示** 保留全部画面；**等比铺满** 会裁掉边缘；**拉伸铺满** 会改变比例。 |
| **横竖切换** | 只在本机切换画面方向，无需打开设备自动旋转，也不改变分享源。 |
| **剧场模式** | 在浏览器标签页内展开画面。 |
| **悬浮小窗** | 浏览器支持时，把视频放进独立小窗。 |
| **全屏观看** | 将画面展开至全屏。 |
| **播放设置** | 调整弹幕外观与连接偏好；连接默认为 **自动**，可选线路取决于房主和站点。 |

</div>

窄屏时，播放栏会排成相邻两行；音量、悬浮小窗、剧场模式与全屏仍可直接操作，无需进入设置。

### 连接偏好

通常保持 **自动**，需要对照某条线路时再选择其他选项。可选线路取决于房主和站点；
选择某条线路，并不会让未开启的服务器或被网络阻断的连接变得可用。

支持的站点还提供 **播放设置 → 连接 → 帮助更多观众转发**，
允许观众为本次访问提供更多上行带宽。它仍是普通 P2P 转发；请在连接稳定、上行有余量时开启。
这个选项需要更新 Server／网页，旧版站点不会出现。
