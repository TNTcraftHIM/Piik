# 分享与播放

本页适用于 3.0 内测版；正式版请看 [正式版文档](https://piik.tv/docs/zh/)。

[English](./sharing.md) · 简体中文 · [文档中心](./README.zh-CN.md)

打开站点或创建房间，请先看[快速上手](./getting-started.zh-CN.md)。
获准进入房间的人都可以分享，多个人可同时开播，再各自选择想看的画面。

[一起看网页视频](#一起看网页视频)

## 开始分享或切换来源

1. 选择房间，点击房间顶部的 **开始分享**。
2. 按可用选项选择 **浏览器 → 共享画面**、**摄像头**，或 App 的窗口或屏幕，再选择具体来源与声音。
   App 选源器可能提示你到 App 中完成选择。
3. 确认本机预览。朋友会在 **正在分享** 列表看到你的画面，点击 **观看** 即可接收。

iPhone／iPad 分享屏幕需使用 iOS／iPadOS 27 及以上的 Safari；观看和摄像头分享不受此屏幕分享门槛限制。
Safari 的屏幕采集不包含系统声音，参阅[浏览器兼容记录](https://github.com/mdn/browser-compat-data/pull/30732)。

![选源器中的示例应用窗口与来源声音开关。](../assets/guide/channel-source.zh-CN.png#gh-light-mode-only)
![选源器中的示例应用窗口与来源声音开关。](../assets/guide/channel-source.zh-CN.dark.png#gh-dark-mode-only)

在自己的画面卡片上点 **切换来源** 替换这一路分享。也可以到另一个房间继续分享，不必先结束原来的分享。
切换侧栏里的房间不会停止已有分享、正在观看的画面或已加入的语音，播放声音也会继续。
主区域只显示当前房间的画面。其他房间的画面列在活动提示条中，点击 **返回** 可回到对应房间；
**停止观看** 或 **停止分享** 只结束所选的那一路活动。
换源时，朋友在房间里已经打开的观看窗口会保留，并开始连接新来源。
分享结束后，窗口仍会保留，观众可以自行关闭；另行开始的分享需要重新选择观看。
画面隐藏时会释放远程控制；需要继续操作时，返回对应房间后重新申请控制。

普通访问可发送站点地址或公开房间链接。私密房间使用自己的邀请或密码，私密邀请只发给你想邀请的人。
每位房主管理自己房间的访问方式与邀请重置，见[快速上手](./getting-started.zh-CN.md)。

## 用 OBS 分享画面和声音

1. 在运行 OBS 的电脑上打开 Piik App。进入房间，点 **开始分享 → OBS / WHIP**。
2. 在 OBS 的 **设置 → 直播** 中，将「服务」设为 **WHIP**。从 Piik 复制 **Server** 和 **Bearer Token**，分别填入 OBS 的服务器地址和令牌栏。[OBS 设置配图](https://obsproject.com/kb/whip-streaming-guide)
3. 在 OBS 中使用 **H.264** 视频和 **Opus** 音频，然后点 **开始推流**。Piik 显示「正在分享 OBS 画面」后，观众在房间里点 **观看**。

如果 Piik 提示视频格式不受支持，先停止推流，在 OBS 的 **设置 → 高级 → 视频 → 色彩格式** 选 **NV12**，再重新推流。部分 Linux 版 OBS 会一直停在连接中。想先分享画面，可以在 OBS 启动虚拟摄像头，再按[摄像头与虚拟音频输入](#摄像头与虚拟音频输入)设置画面和声音。

## 一起看网页视频

在 3.0 内测房间里点击 **开始分享 → 浏览器 → 同步观看**，粘贴视频直链或浏览器地址栏里的网页地址。

- **视频直链。** 如果有可直接播放的视频链接，点 **开始同步观看**。
- **YouTube 或 peertube.tv 视频。** 粘贴受支持的 YouTube 视频链接或 peertube.tv 的单条公开点播视频链接，点 **选择视频**，在预览里播放后点 **开始同步观看**。观众可在自己的浏览器中观看同一视频。
- **分享网页视频。** 在 Windows 版 Piik App 中点 **打开网页选视频**。按需登录并播放想看的视频，再回到 Piik。如果发现多个视频，点选想分享的那个。只发现一个时，Piik 会自动准备。如需更改观众接收所选视频的方式，展开 **播放方式**。如有可选轨道，可在 **轨道选项** 中选择画面和音轨。准备好后点 **开始同步观看**。
- **选择观众的观看方式。** 选 **同步网页里的视频** 时，观众在 Windows 版 Piik App 中打开同一网页，按需登录，选中同一个视频后点 **同步观看**。每台设备从原网站加载视频，跟随分享者的播放。Piik 提供可从原站直接播放的来源时，观众可用支持的浏览器进房点 **观看**。如果有 **从分享者接收** 按钮，观众可改用分享者的 App 接收视频，这会使用分享者的上传带宽。

直链支持视频文件、受支持的 HLS 视频流，以及无 DRM 的静态 DASH（`.mpd`）视频流。

**同步网页里的视频**只同步所选视频的播放。网站在这个播放器里重新加载媒体后，播放仍会同步。要转发新加载的媒体，需要重新选择来源。想让朋友看到整个网页，可以用 **浏览器 → 共享画面** 分享标签页。

在 App 网页小窗的右上角点 **分享…**，就能重新选择这页里的视频。准备好后点 **切换视频**。
取消选择时，当前分享继续播放。

如果你正在 Windows 版 Piik 里看朋友分享的网页视频，点 **播放设置 → 打开网页选视频** 可以换到网站自己的播放器。挑选时当前视频会继续播放，选中同一个视频，再点 **同步观看** 确认切换。想继续看原来的画面，点 **取消** 即可。

如果视频支持直接播放，点 **播放设置 → 从网站直接播放** 可以切回 Piik 播放器。如果出现播放器预览，在预览里点播放即可切换。

从网站直接播放时，各自的设备从原站加载视频。要换到另一集，分享者点 **切换来源**，观众再加入新的共看。

## 分享设置

开播前，从 **开始分享** 旁打开 **分享设置 → 画面**；开播后，入口移到对应画面卡片上。
浏览其他房间时，先点击活动提示条中的 **返回**，再调整这一路分享。
先选画质预设；需要指定分辨率、帧率或码率时，再展开 **画面细调**。
视频编码在开始分享前选择，可用编码取决于浏览器或连接的 App。

![分享设置提供常用预设，详细画面参数可单独展开。](../assets/guide/channel-quality.zh-CN.png#gh-light-mode-only)
![分享设置提供常用预设，详细画面参数可单独展开。](../assets/guide/channel-quality.zh-CN.dark.png#gh-dark-mode-only)

- **分辨率** 表示上限，竖屏和超宽屏仍保留来源比例。
- **滑块** 提供常用值，也可在输入框内填写其他允许值；**返回常用范围** 可回到滑块范围。
- **声音** 包含来源音频质量；分享期间还可调整分享麦克风。

Piik 会根据来源、设备与连接，在这些上限内调整画面。
平台支持情况见 [Native 使用说明](../../prototype/channel-native/README.md)（英文）。

### 给分享起个名字

分享默认使用所选来源的名称。在这一路的 **分享设置** 中展开 **分享标题**，输入名称并 **保存**。
切换来源会保留你的标题；清空输入框再保存，即可恢复使用当前来源的名称。

### 分享麦克风

分享期间，在 **分享设置 → 声音** 中开启 **麦克风或虚拟音频输入**，把你的讲解加入画面，
并在这里选择输入设备、音量和语音处理。每次新分享默认关闭，停止该分享时结束。

观看者通过画面声音收听，不必加入语音。[房间语音](./room-tools.zh-CN.md#房间语音)独立运行，
同时开启两路可能让朋友听到两次你的声音，保留需要的一路即可。

## 摄像头与虚拟音频输入

在 **摄像头** 中允许访问画面后，点击对应的预览卡片。分享一台摄像头时，其他摄像头只显示名称。
摄像头自带的麦克风仍需单独选择，用作分享麦克风或房间语音输入。

OBS 虚拟摄像头提供画面；需要带上 OBS 声音时，按
[OBS 音频转接教程](https://obsproject.com/kb/video-call-streaming-tutorial/)设置音频输入，
再在 **分享设置 → 声音** 中开启 **麦克风或虚拟音频输入** 并选择该设备，声音就会随画面传给观看者。
播放音乐或已处理的虚拟音频时，可关闭这里的语音处理。

## 分享屏幕时排除语音软件的声音

Windows App 的 **屏幕 → 系统声音 → 共享哪台播放设备的声音** 可以选择采集设备。
**系统默认** 跟随 Windows；选定具体设备后，只分享该设备的声音。设备断开时，
画面和麦克风继续分享。需要排除某个应用时，先选回 **系统默认**。

连接的 Windows App 提供排除功能时，**屏幕 → 系统声音** 可排除指定应用及其子进程。
**程序 / 窗口** 则在支持时采集所选应用的声音。

1. 在 **屏幕** 中开启 **系统声音**。
2. 在 **排除应用声音** 中选择语音软件的窗口；没有列出时，先打开该窗口，再刷新列表。
3. 选择要分享的屏幕。支持的开播后调整仍位于 **分享设置 → 声音**。

其他应用或混音软件仍可能带上这些声音。关闭 Piik 麦克风后仍能听到自己的声音时，
可暂时关闭来源声音对照，检查混音软件的播放输出或监听。
排除不可用时，可只分享目标应用的声音，或为语音软件选择另一播放设备。
如果观众听到自己的声音，可以[检查回声来自哪里](./troubleshooting.zh-CN.md#回声或传出了多余的应用声音)。

## 播放控制

**更多选项 → 播放设备** 可以选择当前页面中的视频、房间语音和提示音从哪里播放。
网站内嵌播放器和独立网页窗口使用系统播放设备。
如果列表只有默认设备，允许此页面使用麦克风后再刷新设备列表。

### 观看与排列画面

在别人的分享旁点击 **观看**。可以保留多个房间的观看，主区域排列当前房间的画面。
点击画面卡片或 **聚焦** 可放大其中一个；选择 **平铺画面** 或 **返回平铺** 再看该房间的其他画面。

每路分享的眼睛图标旁显示正在观看的人数，点击可查看名单；分享者和观众都能查看。

鼠标移到画面上，或轻点画面，即可显示播放栏。

| 控件 | 作用范围 |
| --- | --- |
| 播放／暂停 | 只改变自己的本地播放。 |
| 音量 | 观看别人的画面时只调整自己收听；自己的预览中调整的是传给观看者的来源声音，本机预览保持静音。 |
| 播放设置 | 调整本机的画面适配、旋转和弹幕外观。 |
| 剧场模式 | 在当前标签页内展开聚焦的画面。 |
| 悬浮小窗／全屏观看 | 使用浏览器支持的视频小窗或全屏模式。 |
| 房间小窗 | 将人物、聊天与语音控件放在画面旁，见[房间工具](./room-tools.zh-CN.md#把房间放在画面或游戏旁)。 |

标为 **本机预览** 的画面保持静音，避免重复播放。分享音量仍由开始分享的页面调整。

## 结束一项活动

- **停止观看** 只关掉你正在看的那一路，不停止来源或其他画面。
- 在自己的画面卡片上点 **暂停分享**，暂停朋友看到的这一路；**继续分享** 可恢复。
- **停止分享** 结束该来源及其分享麦克风，不结束房间聊天或已加入的语音。

语音需单独点击 **退出语音**。保留当前活动需要的 App 和网页；
Browser 与 App 托管房间的区别见[快速上手](./getting-started.zh-CN.md)。
