# 分享与播放

[English](./sharing.md) · 简体中文 · [文档](./README.zh-CN.md)

把游戏、窗口或整个屏幕分享给朋友。你可以选择是否让朋友听到游戏声，也可以把自己的麦克风声音加进分享。

## 开始分享

1. 在房间里点击 **开始分享**。还没有房间时，先看[快速上手](./getting-started.zh-CN.md)。
2. 选择要给朋友看的画面。

   | 想分享什么 | 怎么选 |
   | --- | --- |
   | 浏览器标签页、窗口或屏幕 | 选 **浏览器**，再点 **选择画面**。弹窗里有哪些选项，取决于浏览器和设备。 |
   | 电脑游戏或应用 | 连接 Piik App 后，如果有 **程序 / 窗口**，打开它并选中游戏或应用。 |
   | 电脑的整个屏幕 | 连接 Piik App 后，如果有 **屏幕**，打开它并选中要分享的显示器。 |
   | 摄像头画面 | 选 **摄像头**，允许访问后选择摄像头。 |

3. 如果选了 **浏览器**，可在浏览器弹窗里开启音频（如果有），并在该弹窗中确认。如果选了 App 的窗口或屏幕，按需设置 **应用声音** 或 **系统声音**，再点 Piik 选择窗口底部的 **开始分享**。
4. 确认预览画面，分享期间保持房间页面打开。想让朋友也听到你说话，可以[分享麦克风](#分享麦克风)。

找不到选画面的弹窗，或选好后无法分享，请看[开始分享时的常见问题](./troubleshooting.zh-CN.md#开始分享)。朋友看得到画面却听不到游戏声，请看[有画面但没有来源声音](./troubleshooting.zh-CN.md#有画面但没有来源声音)。

![App 选源窗口已选中一个窗口，并显示应用声音开关和开始分享按钮。](../assets/guide/share-source-confirm.zh-CN.png#gh-light-mode-only)
![App 选源窗口已选中一个窗口，并显示应用声音开关和开始分享按钮。](../assets/guide/share-source-confirm.zh-CN.dark.png#gh-dark-mode-only)

如果你能看到自己的预览，但朋友仍看不到画面，请看[如何检查你和朋友之间的连接](./no-media-route.zh-CN.md)。

## 用手机或平板分享

- **安卓。** 在 Android 10 或更新版本上使用 Piik App。从已安装的 App 打开 Piik，并在安卓弹窗里同意分享屏幕。分享会显示整个屏幕，允许安卓录制播放声音的应用也可以带上声音。[安装和打开 Piik App](./getting-started.zh-CN.md#用-piik-app-分享)
- **iPhone 和 iPad。** 分享屏幕需要 iOS 或 iPadOS 27 及以上版本的 Safari。[iPhone 与 iPad 屏幕分享](#iphone-与-ipad-屏幕分享)

## 切换、取消或停止分享

- **换一个画面。** 点击画面下方的 **切换来源**，再选要分享的新画面。
- **选画面时取消。** 关闭 Piik 的选择窗口，或在浏览器或系统弹窗中取消。如果是从 **切换来源** 打开的，朋友会继续看到原来的画面。
- **结束正在进行的分享。** 点击画面下方的 **停止分享**。用手机分享时，先回到房间页面。

## 邀请

**复制邀请链接** 会授予房间访问权，请只发给你想邀请的人。
关闭链接旁的 **免密邀请** 可复制普通房间地址，访客按站点和房间要求输入口令或密码；
仅限邀请的房间仍需邀请凭证。已发邀请持续有效，直到房主点击 **更新链接** 或 **撤销链接**；
这两项操作会断开通过旧邀请加入的观众。

## 播放控制

将鼠标移到画面上，或轻点画面，即可显示播放控制栏。

- 画面上的播放／暂停按钮只影响自己看到的画面。房主调画面上的音量，会改变发给所有观众的声音。房主自己的预览保持静音，避免同一个声音放两遍。观众调画面上的音量，只改变自己听到的声音。
- **暂停朋友看到的画面：** 点击画面下方的 **暂停分享**，影响所有观众。
- **控制自己的麦克风与收听：** 打开 **互动 → 语音**，与画面声音分开控制。

<div class="guide-control-reference">

| 按钮 | 作用 |
| --- | --- |
| **音量** | 支持增强时最高 200%，否则最高 100%；声音失真时调低一些。 |
| **画面显示** | 点击切换：**完整显示** 保留全部画面；**等比铺满** 会裁掉边缘；**拉伸铺满** 会改变比例。 |
| **横竖切换** | 只在本机切换画面方向，无需打开设备自动旋转，也不改变分享源。 |
| **剧场模式** | 在浏览器标签页内展开画面。 |
| **悬浮小窗** | 浏览器支持时，把视频放进独立小窗。 |
| **全屏观看** | 将画面展开至全屏。 |
| **播放设置** | 调整弹幕外观与连接偏好；连接默认为 **自动**，可选线路取决于房主和站点。 |

</div>

### 连接偏好

通常保持 **自动**。想试试其他连接方式时，选择房主与站点提供的其他选项。

房主可在 **分享设置 → 连接设置 → 房间转发上限** 设置每台设备默认最多发送几路，
这不是房间的观众总人数限制。

观众默认跟随房间。在 **播放设置 → 连接** 开启 **自定义转发上限**，
即可为本次观看单独调高或调低；设为 **0** 时只接收、不向下游转发。
上限越高，可能使用的上行带宽越多；可用范围取决于设备能力。
旧站点只提供 **提高本机转发上限**。

纯 P2P 房间的上限设为 **1** 时，首位观众需要继续转发，后面的人才能通过他连接。
如果他设为 **0**，可提高房间上限或他的个人上限，让路由重新安排线路。

## 画面与声音设置

1. 在画面下方打开 **分享设置 → 画面**。
2. 先选画质预设；需要指定分辨率、帧率、码率、画面偏好或视频编码时，再展开 **画面细调**。
3. 切到 **声音**，选择来源声音和输出质量。

![画面页签列出「轻量」「高清」和「高帧率」三种预设，当前选中「高清」。](../assets/guide/sharing-settings.zh-CN.png#gh-light-mode-only)
![画面页签列出「轻量」「高清」和「高帧率」三种预设，当前选中「高清」。](../assets/guide/sharing-settings.zh-CN.dark.png#gh-dark-mode-only)

| 设置 | 怎么理解 |
| --- | --- |
| 分辨率 | 表示上限；竖屏和超宽屏仍保留来源比例。 |
| 滑块与自定义数值 | 滑块提供常用值，也可在输入框允许的范围内自定义；**返回常用范围** 可回到附近档位。 |
| 画面与声音质量 | 仍会根据来源、设备和可用带宽调整。 |

如果多位观众一直看到模糊或不流畅的画面，房主可试着降低分辨率或帧率，同时查看预览。
如果房主预览流畅，但你观看时画面偶尔停一下，可在画面上的 **播放设置** 中开启 **增加播放缓冲**（如果有此选项）。
缓冲会增加延迟，操作明显变慢时可关闭。更多步骤见[画质检查](./troubleshooting.zh-CN.md#画面模糊卡顿或中断)。

已应用的设置会保存在当前站点；通过新版 App 打开时，更换公网邀请网址也能保留分享画质设置。

### 分享麦克风

在 **分享设置 → 声音** 中开启 **分享麦克风**，可将你的声音加入分享画面。
每次开始新的分享时默认关闭，停止分享也会停止这路麦克风。观众通过画面声音收听，无须加入房间语音。
房间语音独立运行。如果同时开启两路麦克风，听众可能听到两次你的声音；Piik 会提示，由你决定保留哪一路。

## iPhone 与 iPad 屏幕分享

请使用 **iOS／iPadOS 27 及以上的 Safari**，选择 **浏览器** 分享屏幕。
观看朋友的画面和分享摄像头使用浏览器已有能力，不受此屏幕分享版本门槛限制。

Safari 屏幕分享**不采集系统声音**。需要随画面讲话时，可主动开启[分享麦克风](#分享麦克风)。
依据 MDN 的 [Safari 27 实测记录](https://github.com/mdn/browser-compat-data/pull/30732)
及[屏幕／音频兼容数据](https://github.com/mdn/browser-compat-data/blob/main/api/MediaDevices.json)，两者支持情况不同。

## 摄像头与虚拟音频输入

![来源声音与分享麦克风随画面传输，使用播放音量；房间语音使用独立的收听音量。](../assets/guide/audio-paths.zh-CN.svg)

摄像头分享只请求画面权限。在 **摄像头** 页签中允许访问后，点击对应的画面卡片开始分享。
设备名称和可用预览取决于浏览器权限；正在分享摄像头时，其他摄像头只显示名称。
带麦克风的摄像头仍需分别选择画面和音频输入。OBS 虚拟摄像头只提供画面；
如需带上 OBS 的声音，可按 [OBS 音频转接教程](https://obsproject.com/kb/video-call-streaming-tutorial/)
设置虚拟音频设备，再在 **分享设置 → 声音** 中选择对应的分享麦克风输入，
或在[房间语音的麦克风设置](./room-tools.zh-CN.md#房间语音) 中选择输入，使用独立的实时语音频道。

## 分享屏幕时排除语音软件的声音

如果 Piik 和要分享的内容在同一浏览器的不同标签页，请选浏览器来源，在浏览器弹窗中选播放内容的标签页并开启标签页音频。这样你仍能听到房间通话，观众也能听到该标签页的声音。在 Windows 排除整个浏览器进程也可能排除其他标签页的声音。

在 Windows 上，此控件用于 **屏幕** 分享的系统声音。**程序 / 窗口** 只采集所选应用及其子进程的声音；
**摄像头** 分享画面，麦克风或虚拟音频输入需要单独开启分享麦克风或房间语音。

1. 打开 **屏幕** 页签，开启 **系统声音**。
2. 在 **排除应用声音** 中选择语音软件的窗口。未列出时，先打开窗口，再刷新列表。
3. 选择要分享的屏幕。

此功能从系统声音中排除所选进程及其子进程。其他应用仍会被采集，包括单独的混音软件，
以及使用其他播放设备的应用。只需要一个应用的声音时，可改为分享 **程序 / 窗口**。
扬声器被麦克风再次收音时，请使用耳机。

使用虚拟麦克风时，如果关闭 Piik 麦克风后仍能听到你的声音，可暂时关闭 **系统声音**，看声音是否消失。
若声音随之消失，请检查混音软件的播放输出与监听，或改为只分享目标应用的窗口音频。

开播后，可在 **分享设置 → 声音** 中调整系统声音和排除的应用，无需停止分享。
所选应用关闭或重启后，来源声音会停止；请刷新应用列表并重新选择。
暂时关闭来源声音会保留排除选择；需要恢复完整的系统声音时，选择 **不排除**。
连接的 Windows App 和系统支持排除时，会显示此选项。未显示时，可改为分享单个应用窗口，
或将语音软件输出到另一播放设备。
