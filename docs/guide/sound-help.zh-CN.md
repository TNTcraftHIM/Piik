# 游戏没声音、听不到朋友或有回声

[English](./sound-help.md) · 简体中文

[游戏没声](#有画面但听不到游戏声音) · [听不到朋友](#听不到朋友说话) · [朋友听不到我](#朋友听不到我说话) · [听见回声](#我能听见自己的回声)

## 有画面但听不到游戏声音

1. 请房主播放一段自己能听见的游戏声音。观众点一下画面，如果播放器已静音，点 **取消静音**，再调高音量。如果只有你听不到，检查你的耳机或扬声器。
2. 如果所有观众都听不到，请房主重新选择分享的内容，并打开声音。iPhone 和 iPad 上的 Safari 分享屏幕时只能传画面，房主仍可开启 **分享麦克风**。使用摄像头（包括 OBS 虚拟摄像头）时，房主要单独选择音频输入。[分享来源与声音设置](./sharing.zh-CN.md)
3. Windows App 分享整屏且未排除应用声音时，请房主在 Windows 声音设置里查看默认输出设备，确认游戏用的也是这个设备。房主也可以只选游戏窗口分享，再请观众试听。

## 听不到朋友说话

先问朋友是通过哪种方式说话。如果房主打开了 **分享麦克风**，声音随画面播放。请房主检查 **分享设置 → 声音**，观众取消画面静音。

使用房间语音时，房主先 **开启房间语音**，两人都打开 **互动 → 语音**，点击 **加入语音**。请发言的人打开麦克风。如果别人能听见这位朋友，检查自己是否暂停收听，或单独将对方静音。[房间语音控件](./room-tools.zh-CN.md#房间语音)

## 朋友听不到我说话

1. 打开 **互动 → 语音 → 语音设置**，选中你正在使用的麦克风，检查输入音量并允许浏览器使用麦克风。请一位朋友试听。**暂停收听** 只会暂停你听到的声音。
2. 如果浏览器无法开麦，通过房主发送的完整 HTTPS 邀请重新加入。如果打开的是本地房间邀请，且浏览器显示证书警告，先与房主核对证书。如果浏览器无法接受本地证书，请房主发一个浏览器信任的 HTTPS 邀请。[核对本地证书](./troubleshooting.zh-CN.md#本地-https-证书提示)
3. 如果双方都看到 **语音连接异常**，先用另一款浏览器打开同一个邀请。仍然连不上时，再换手机热点重试。[检查语音连接](./network.zh-CN.md)

## 我能听见自己的回声

1. 保持房间语音开启，把直播画面的播放音量调到零，说一句话。如果回声消失，恢复播放音量，请房主暂时关闭分享来源的声音。整屏分享时对应 **系统声音**。
2. 如果回声再次消失，而且房主仍听得到你，是分享把通话声传了回来。房主可只分享游戏窗口，或在整屏分享时排除播放通话的应用。如果游戏和通话在同一浏览器里，分享游戏标签页并开启标签页音频。[排除语音软件的声音](./sharing.zh-CN.md#分享屏幕时排除语音软件的声音)
3. 如果直播静音后仍有回声，让使用扬声器的人戴上耳机。如果关掉来源声音后仍有回声，也可让房主暂时关闭 **分享麦克风**。

<details>

暂时关闭 **系统声音**。如果重复的声音消失，检查混音器把哪路声音送到了默认播放设备。调整监听输出后，恢复系统声音并请朋友再听一次。
