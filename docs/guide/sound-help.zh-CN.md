# 游戏没声音、听不到朋友或有回声

[English](./sound-help.md) · 简体中文

## 有画面但听不到游戏声音

1. 让房主播放一段自己能听见的游戏声音。点一下画面，取消视频静音，调高播放音量。如果另一位观众能听见，再检查你的耳机和设备音量。
2. 如果所有观众都听不到，请房主重新选择分享的内容，并打开声音。iPhone Safari 分享屏幕时无法传送游戏声音。使用摄像头（包括 OBS 虚拟摄像头）时，房主需要另选音频输入。[分享来源与声音设置](./sharing.zh-CN.md)
3. Windows App 分享整屏且未排除应用声音时，游戏需要通过默认播放设备发声。房主也可以只选游戏窗口分享，再请观众试听。

## 听不到朋友说话

先问朋友是通过哪种方式说话。如果房主打开了 **分享麦克风**，声音随画面播放。请房主检查 **分享设置 → 声音**，观众取消画面静音。

使用房间语音时，房主先 **开启房间语音**，双方加入 **互动 → 语音**。请发言的人打开麦克风。如果别人能听见这位朋友，检查自己是否暂停收听，或单独将对方静音。[房间语音控件](./room-tools.zh-CN.md#房间语音)

## 朋友听不到我说话

1. 在 **语音设置** 中选中你正在使用的麦克风，检查输入音量并允许浏览器使用麦克风。请一位朋友试听。**暂停收听** 只会暂停你听到的声音。
2. 如果浏览器无法开麦，通过房主发送的完整 HTTPS 邀请重新加入。如果设备提示证书有问题，请房主改发当前的 **公网邀请**。
3. 如果双方看到语音连接错误，试用另一款浏览器或手机热点。[检查语音连接](./network.zh-CN.md)

## 我能听见自己的回声

1. 保持房间语音开启，把直播画面的播放音量调到零，说一句话。如果回声消失，恢复播放音量，请房主暂时关闭分享来源的声音。整屏分享时对应 **系统声音**。
2. 如果回声再次消失，而且房主仍听得到你，是分享把通话声传了回来。房主可只分享游戏窗口，或在整屏分享时排除播放通话的应用。如果游戏和通话在同一浏览器里，分享游戏标签页并开启标签页音频。[排除语音软件的声音](./sharing.zh-CN.md#分享屏幕时排除语音软件的声音)
3. 如果直播静音后仍有回声，让使用扬声器的人戴上耳机。如果关掉来源声音后仍有回声，也可让房主暂时关闭 **分享麦克风**。

<details>
<summary>使用虚拟混音器时检查监听输出</summary>

暂时关闭 **系统声音**。如果重复的声音消失，检查混音器把哪路声音送到了默认播放设备。调整监听输出后，恢复系统声音并请朋友再听一次。
