# 聊天、语音与远程控制

本页适用于 3.0 内测版；正式版请看[维护版指南](https://github.com/TNTcraftHIM/Piik/blob/main/docs/guide/room-tools.zh-CN.md)。

[English](./room-tools.md) · 简体中文 · [文档中心](./README.zh-CN.md)

一个站点里可以有多个房间。在侧栏选择房间后，就能阅读该房间的聊天。
获准进入房间的人都可以聊天、加入语音、分享画面或观看别人的分享。
每个人都能创建并管理自己的房间；站点维护者只管理站点名称、图片和备份。

点击自己名字旁的 **修改个人资料**，更换昵称或头像。同一张头像会出现在聊天、语音名单
和沙发小人的身体里；选择 **移除头像** 可恢复纯色小人。

右侧用户列表按 **当前房间**、**在线**、**离线** 分组。左侧房间下方显示正在参与语音、分享、观看或文件传输的人，
包括实际协助转发的参与者；耳麦、分享和观看图标显示各自的活动。折叠名单不会结束活动。

## 管理房间

打开房间列表（窄屏先点**房间列表**），再点对应房间旁的设置按钮。
这不会切换当前聊天或停止活动。标签页按你的权限提供这些操作：

- **房间：** 修改名称、图片或访问方式，再点**保存**。**对未获准的用户隐藏房间**会让尚未获准的人看不到该私密房间。在**已获准的用户**中，**移除房间资格**会结束该用户在此房间的访问和活动；再次进入需要重新获准。
- **连接：** 选择这台设备在本房间最多帮多少人转发。
- **记录：** 导出已加载的聊天文字。房主还可导出完整备份，或生成可交给别人创建新房间的副本。

邀请在房间标题旁打开，可复制链接，或使用复制操作下方的二维码按钮。公开房间分享直达链接，私密邀请只授予该房间的资格。
切换到公开会保留已有的私密邀请密钥，但普通公开入场不会自动获得后续私密资格。
重置私密邀请会使旧链接失效，但保留已获准用户的资格。
有密码时可选择**免密邀请**或**需密码链接**。后者的新访客需输入密码，已获准的用户可直接进入。
需要换新链接时，展开**重置房间邀请**，再点**确认重置邀请**。
站点维护者点击房间列表上方的站点名称，即可打开站点设置。

### 备份或复制房间

保留原房间时，在**记录 → 导出完整备份**保存 ZIP；恢复时选择**恢复完整备份**，核对替换提示后确认。
备份包含房间设置、完整消息记录和本机留存文件。

交给别人另建房间时，选择**导出房间副本**，可勾选是否附带房间信息。
对方在**创建房间 → 载入房间副本**选择 ZIP，设置新名称和访问方式后创建。
消息、回应次数和可用附件会保留，新房间由对方自己的账号管理。

**站点备份**只保存站点资料与房间目录。各房主分别备份自己的房间，无需把全部聊天和文件集中到站点维护者。

## 聊天与表情

1. 选择房间，在聊天输入框中发送消息。点击附件按钮可添加图片或文件，也可以同时附上文字。
2. 悬停消息，或用键盘聚焦回应按钮，显示 **回应这条消息**；触屏上按钮保持可见。已有次数常驻消息下方，每次确认后次数加一；短暂冷却后再次点击同一表情会继续累加。
3. 点击 **更早的消息** 向前阅读；**最新消息** 可回到当前聊天。

房间旁的未读圆点表示上次阅读后有新消息。在前台聊天界面读到最新消息底部即可清除，
本浏览器会记住阅读位置。后台语音或观看画面不会自动把聊天标为已读。

输入 `@` 后选择用户即可提及对方，昵称改变也不会指向别人。点击消息旁的**回复这条消息**，
原文会显示在输入框上方；取消回复会保留草稿，也可以关闭该回复的**提醒回复对象**。
点击已发送的引用可跳到原消息，再点**最新消息**返回。

桌面端按 Enter 发送、Shift+Enter 换行；触屏键盘的回车换行，点击 **发送** 发出消息。
也可用 Ctrl+Enter 或 Command+Enter 发送。

确认发送的消息和消息表情次数由托管房间的一端保存。刷新页面或重新进入时，
房间托管端在线即可重新载入历史。聊天与历史通过站点连接传送，不必等待 P2P 连通；
站点会转发聊天正文，但不保存房间历史。附件记录保留在聊天中，不代表文件始终在线；
有参与者持有可读取的副本时，才能打开或下载。

点击房间里的人物可以打开互动菜单。人物表情与投掷道具是实时效果，不会保存为消息表情。
每个画面的观看人数旁显示表情和次数，操作与消息相同。点击已有表情继续回应，或用 **回应此画面** 选择其他表情。
不同分享分别计数，停止分享时结束；载入已有次数不会重播动画。

在 **更多选项 → 提示与互动声音** 开启本浏览器的提示音，默认关闭。
网页处于后台时，新消息会播放轻提示；在前台发出或收到番茄、便便时会播放短音效。
可单独调节音量，点击 **试听** 检查效果。
消息提醒和投掷音效都可选择本地音频，每个文件最多 256 KiB、3 秒；可分别试听或恢复内置音效。
自定义音效只保存在当前浏览器，不会发送给房间里的其他人。

每条消息合计不超过 64 KiB 的小图随聊天传送并保存，GIF 保留动画。点击图片或用户头像可放大查看，
按 Escape 或关闭按钮回到房间。较大图片和其他文件按需走房间的 P2P 路径，并复用已有连接。

观看画面时，播放栏的 **弹幕** 可显示该房间的新消息；在 **播放设置 → 弹幕** 中调整外观。
加载旧记录不会重播弹幕。系统视频全屏和视频画中画不显示弹幕。

## 房间语音

1. 在左下方个人区域点击 **加入语音**，按提示允许使用麦克风，无需房主先开启通话。
2. 使用常驻语音控件开关麦克风、暂停收听或 **退出语音**；在 **语音设置** 中选择输入设备、降噪与回声消除。

![示例房间的聊天区域与下方已加入的语音控件：麦克风、收听、设置和退出。](../assets/guide/channel-room.zh-CN.png#gh-light-mode-only)
![示例房间的聊天区域与下方已加入的语音控件：麦克风、收听、设置和退出。](../assets/guide/channel-room.zh-CN.dark.png#gh-dark-mode-only)

悬停在麦克风、耳机或某个人的扬声器按钮上可调节音量，触屏上可长按。
房间名左侧的小箭头可以收起或展开语音名单。
静音某个人只影响你听到的声音。麦克风和收听控件不改变分享画面的声音。
房间管理者还可在语音设置中调整 **房间语音码率**。
麦克风按钮里的绿色填充随你的声音变化；收到朋友的声音时，语音栏里人物的麦克风会亮起。
耳麦展开本身只表示已开麦。

可以同时加入多个房间的语音。加入多个房间后，用语音房间选择框确定正在操作哪个房间的
麦克风、收听和退出按钮。切换聊天房间或停止画面分享不会退出这些语音；结束时分别退出即可。

浏览器开麦需要安全环境，例如已接受的 HTTPS 或 localhost。
本地访问见 [App 使用参考](../../prototype/channel-server/README.md#local-app-link)，
平台要求见 [Native 媒体说明](../../prototype/channel-native/README.md)（英文）。

### 来源声音、分享麦克风与房间语音

- **来源声音** 来自分享的标签页、程序或屏幕，随画面播放控件调整。
- **分享麦克风** 把你的讲解加入画面，观看者无需加入语音就能听到；停止该分享时结束。
- **房间语音** 是独立的聊天通话，单独加入，也有自己的收听控件。

同时开分享麦克风和房间语音，可能让朋友听到两次你的声音，保留需要的一路即可。
建议使用耳机；系统声音采集还可能再次采到浏览器正在播放的朋友声音。
相关操作见[分享声音设置](./sharing.zh-CN.md#分享屏幕时排除语音软件的声音)。

## 把房间放在画面或游戏旁

点击沙发旁的 **弹出房间小窗**，直接把聊天、人物和语音控件移到置顶小窗。
其他浏览器使用页面内可移动的 **房间交流面板**。
保持原页面打开；关闭小窗，或再次点击同一个房间小窗按钮，会将控件和草稿收回页面。

打开或关闭小窗不会加入或退出语音。游戏使用窗口或无边框模式时更方便查看，独占全屏可能遮住小窗。

## 让朋友操作共享的电脑

通过 App 分享窗口或屏幕，在该分享上开启 **远程控制**，再允许朋友的请求。
获准进入房间不等于获准控制电脑。观看者从对应画面的播放栏申请控制，结束时点击 **结束控制**；
分享者也可撤回许可或停止该分享。

平台要求见 [Native 输入说明](../../prototype/channel-native/README.md)（英文）。每个人的分享分别授权。
