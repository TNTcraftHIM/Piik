# 聊天、语音与远程控制

[English](./room-tools.md) · 简体中文 · [文档中心](./README.zh-CN.md)

这些工具以房间为单位。开播前、停播后都可以聊天；远程控制需要房主正在通过 App 分享窗口或屏幕。

## 聊天与表情

房主创建房间后，参与者可以点击沙发下方的 **互动** 发送消息。
点击沙发上的人物可打开表情菜单：给自己发的表情出现在头顶，送给朋友的表情会飞向对方。
聊天或语音列表中的头像也能打开快捷表情菜单；点击 **更多表情** 可展开完整选择，同时继续看消息和聊天。
互动窗口可以移动和缩放，不会挤动页面。

支持的桌面浏览器会在窗口右上角显示 **在置顶窗口中打开**，方便玩游戏时看消息、接收表情，
也可以在小窗中选人互动。保持 Piik 页面打开；关闭小窗会将它收回页面。建议游戏使用窗口或无边框模式，
独占全屏不保证显示置顶窗。小窗目前不支持透出游戏画面或鼠标穿透。

输入框旁和观众播放控制栏中的 **弹幕** 可以把新消息显示在画面上，默认关闭，只影响自己的观看。
通过互动窗口中的 **聊天设置** 调整字号和不透明度；播放设置负责画面显示和连接偏好。
系统视频全屏和画中画无法显示弹幕。

停止分享后仍可继续聊天；App 的本地房间和公网邀请需要保持 App 运行。
每个页面只保留本页最近收到的消息，刷新后清空，后来加入的人看不到此前的记录。
需要留存时，可通过 **聊天设置 → 导出聊天记录** 将本页保留的最近消息（最多 1,000 条）保存为文本文件。
聊天消息经过房间所在的服务器，**不提供端到端加密**。

## 测试版房间语音

房主可先点击 **创建房间**、复制邀请，不必立即开播。
打开 **互动 → 语音**，点击 **开启房间语音**，房间成员即可自行 **加入语音**，不需要再次审批。
加入不会打开麦克风；发言者仍需自己点击 **打开麦克风**，并允许浏览器访问。
开麦需要浏览器接受的 HTTPS 页面或本机地址；普通内网 HTTP 页面仍可加入收听。
局域网或虚拟局域网下需要开麦、远控时，参阅[虚拟局域网说明](./troubleshooting.zh-CN.md#可选虚拟局域网)。
**本地静音** 只改变你自己听到的声音。
加入后，底部工具栏提供麦克风、收听和退出按钮。
**暂停收听** 只暂停你这里的房间语音播放，麦克风、视频声音和语音转发不受影响。
语音页的 **麦克风设置** 可选择输入设备、调整输入音量（默认 100%，最高 200%），
以及开关降噪与回声消除。浏览器与 App 分享都使用这组控件。

停止画面分享后仍可继续语音；关闭或弹出互动窗口也不会退出。
观众可点击 **退出语音**；房主点击 **关闭房间语音** 会结束所有人的语音。
重新开启后，观众仍需自行加入、开麦。
房主说话也使用这个房间麦克风，观众需加入语音才能收听。
来源声音继续跟随画面；房间语音优先保证实时交流，画面延迟时可能先听到说话声。
建议佩戴耳机；分享整个系统声音可能把收到的语音再次传出，支持的 App 采集路径可尝试
[排除应用声音](./sharing.zh-CN.md#分享屏幕时排除语音软件的声音)。

麦克风设置保存在当前站点的浏览器中，不会自动重新开麦。普通说话通常保持降噪与回声消除开启；
如果输入设备已经处理了声音，可关闭它。

## 让朋友操作共享的电脑

1. 通过 Piik App 的 **程序 / 窗口** 或 **屏幕** 开始分享。
2. 打开画面下方的 **远程控制** 并开启开关，默认使用 **每次询问**。
3. 朋友在播放控制栏中点击 **请求控制**。收到请求后，在自己的分享页面选择 **允许控制**。

分享窗口时，允许控制后请切回该窗口。其他窗口处于前台时，远程输入会暂停；切回即可继续。

同一时间只能有一位观众控制，可使用电脑或手机浏览器。更新房主的 App 和房间所在站点后，
观众刷新页面即可。房主开启远控、连接支持后，观众才会看到控制按钮。
浏览器和摄像头采集不支持接收远程操作。
观众需通过 HTTPS 或本机页面使用远控；普通局域网或虚拟 IP 的 HTTP 页面可以观看，
但没有远控所需的浏览器加密接口，因此不会出现控制按钮。

双方都可以点击 **结束控制**。房主还可以在本机按 **Ctrl+Alt+F10**（Windows）
或 **Control+Option+F10**（macOS）立即结束；如与其他应用冲突，可在房主的
**远程控制** 面板中更换功能键。快捷键保存在当前站点的浏览器存储中，各站点独立设置。
观众可以在 **远程键盘** 中单独调整
**退出控制快捷键**，独立键盘窗口也可使用。切换来源或停止分享会关闭远控；
连接中断后，观众需要重新请求。
授权方式会记住，但不会自动开启远控。上次选择 **房间观众** 时，再次开启会先展示
授权说明；点击 **允许观众控制** 后才生效。控制密码不会保存。

手机上滑动可移动鼠标，轻点点击、长按拖动；双指轻点右击、滑动滚动。
捏合可以放大画面，放大后用双指移动查看位置。**远程键盘** 提供按键、组合键和文字输入。
电脑上可开启 **游戏鼠标** 连续转动视角，按 **Esc** 释放鼠标。

<details>
<summary>授权与平台支持</summary>

**房间观众** 允许房间内的观众直接取得空闲控制权；**控制密码** 要求输入单独设置的控制密码。
这些设置只对当前分享来源有效。允许控制后，对方可以操作这台电脑的鼠标和键盘，
请只授权给信任的人；操作范围不受视频画面边界限制。

macOS 需要允许「辅助功能」权限。Linux 需要桌面环境支持 Portal，目前只支持控制所选屏幕，
不支持单个应用窗口。Windows 是主要经过实机验证的房主平台，macOS/Linux 的设备验收仍有限。
受系统保护的快捷键和部分游戏可能无法接收远程输入。
