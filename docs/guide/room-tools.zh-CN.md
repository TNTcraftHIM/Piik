# 聊天、语音与远程控制

本页适用于 3.0 内测版；正式版请看[维护版指南](https://piik.tv/docs/zh/room-tools.html)。

[English](./room-tools.md) · 简体中文 · [文档中心](./README.zh-CN.md)

从侧栏选择一个你能进入的房间，就可以看聊天记录、加入语音、分享屏幕或观看朋友的画面。
站点所有者决定谁可以建房，也可以从站点移除房间。房主管理本房间的设置和邀请。站点所有者要查看私密房间里的消息，也需要先获准进入。

点击自己名字旁的 **修改个人资料**，更换昵称或头像。同一张头像会出现在聊天、语音名单
和沙发小人的身体里；选择 **移除头像** 可恢复纯色小人。

- **沙发**上坐着当前房间里的人，只看聊天的朋友也会出现。
- **左侧房间名下**列出正在语音、分享、观看或传文件的人，也包括帮别人转发的人。名字旁的图标显示他们在做什么。
- **右侧用户列表**显示整个站点的人，分为 **当前房间**、**在线** 和 **离线**。点 **更多用户** 可以继续看离线名单，在聊天框输入 `@` 也可以按名字找人。

## 选择界面

默认使用**完整工作区**。已经在其他软件里语音、只需要 Piik 分享画面时，可以在
**更多选项 → 界面**选择**极简分享**。点击**开始分享**、选择来源，再复制画面下方的邀请链接。
画面、播控和沙发是主要区域，**互动**按钮打开辅助面板。
沙发旁保留**加入语音**；加入后可开关麦克风、收听或退出。打开页面内的互动面板时，主沙发留在原位。
多人可以同时分享，分别点击想看的画面上的**观看**，再选择平铺或聚焦。
平铺会按窗口宽度排列各个画面；聚焦时仍可切回其他画面，停止其中一路不会结束其他画面。

切换界面会保留正在进行的分享、观看、草稿和已加入的语音；已有语音仍可操作或退出。
两种界面都可打开**房间列表**创建或切换房间，也可从**邀请 → 访问设置**打开房间设置，
浏览器会记住你的界面选择。

## 管理房间

打开房间列表（窄屏先点**房间列表**），再点对应房间旁的设置按钮。
这不会切换当前聊天或停止活动。标签页按你的权限提供这些操作：

- **房间：** 修改名称、图片或访问方式，再点**保存**。**对未获准的用户隐藏房间**会让尚未获准的人看不到该私密房间。在**已获准的用户**中，**移除房间资格**会结束该用户在此房间的访问和活动；再次进入需要重新获准。
- **连接：** 选择这台设备在本房间最多帮多少人转发。
- 在**记录**中导出已加载的聊天文字，或点**清除本机房间缓存**，清除当前身份在这台设备上缓存的房间附件。房间记录和已保存的下载保留。仅有本机一份的文件请先保存。

邀请在房间标题旁打开，可复制链接，或使用复制操作下方的二维码按钮。公开房间分享直达链接，私密邀请只授予该房间的资格。
切换到公开会保留已有的私密邀请密钥，但普通公开入场不会自动获得后续私密资格。
重置私密邀请会使旧链接失效，但保留已获准用户的资格。
有密码时可选择**免密邀请**或**需密码链接**。后者的新访客需输入密码，已获准的用户可直接进入。
需要换新链接时，展开**重置房间邀请**，再点**确认重置邀请**。
站点维护者点击房间列表上方的站点名称，即可打开站点设置。

### 备份或复制房间

房主在**房间设置 → 记录 → 导出房间备份**保存 ZIP。备份保留房间身份、房主、访问设置和完整聊天历史，包括存于消息中的图片。勾选**包含本设备的附件原件**可加入本机能读取的原件。

- 要替换在线房间的数据，在该房间的**房间设置 → 记录**中点**恢复房间备份**。选择 ZIP，再确认替换。站点运行期间，即使创建者离线，Server 托管的房间仍可用。
- 如果轻量站点允许你建房，点**创建房间 → 从备份恢复房间 → 恢复房间备份**，选择 ZIP 并确认，恢复原房间和保存的账号。

交给别人另建房间时，选择**导出房间副本**，可勾选是否附带房间信息。
对方在**创建房间 → 载入房间副本**选择 ZIP，设置新名称和访问方式后创建。
消息、回应次数和可用附件会保留，新房间由对方自己的账号管理。

**站点备份**只保存站点资料与房间目录。各房主分别备份自己的房间，无需把全部聊天和文件集中到站点维护者。

## 聊天与表情

1. 选择房间，在聊天输入框中发送消息。点击附件按钮可添加图片或文件，也可以同时附上文字。
2. 悬停消息、用键盘聚焦消息，或在触屏上轻点消息，显示表情、**@**和回复操作。已有表情次数保持可见；每次确认后次数加一，短暂冷却后再次点击同一表情会继续累加。
3. 点击 **更早的消息** 向前阅读；**最新消息** 可回到当前聊天。

房间旁的圆点表示有未读消息。点击**跳转到新消息**，就能从上次读完后别人发的第一条消息开始看。
旧版房间里可以用**更早的消息**向前翻。读到最新消息底部时，圆点消失，浏览器会记住你的位置。

每条消息最多 2,000 字符，支持 Markdown 强调、列表、引用、链接和代码。行内代码用反引号包住；代码块前后各放一行三个反引号，
再用**复制代码**复制不含这些标记的代码内容。代码保持原文，消息中的 HTML 不会执行。

输入 `@` 后选择用户，或使用消息的 **@** 操作，在草稿当前光标或选区插入作者。
提及会保留用户身份，昵称改变也不会指向别人。点击消息旁的**回复这条消息**，
原文会显示在输入框上方；取消回复会保留草稿，也可以关闭该回复的**提醒回复对象**。
点击已发送的引用可跳到原消息，再点**最新消息**返回。

桌面端按 Enter 发送、Shift+Enter 换行；触屏键盘的回车换行，点击 **发送** 发出消息。
也可用 Ctrl+Enter 或 Command+Enter 发送。

轻量站点由房间创建者的设备保存消息和回应，托管站点由服务器保存。托管网页、App 或服务器正在提供房间服务时，
重新打开房间就能读取历史。聊天使用站点连接。

点击房间里的人物可以打开互动菜单。人物表情与投掷道具是实时效果，不会保存为消息表情。
每个画面的观看人数旁显示表情和次数，操作与消息相同。点击已有表情继续回应，或用 **回应此画面** 选择其他表情。
不同分享分别计数，停止分享时结束；载入已有次数不会重播动画。

在 **更多选项 → 提示与互动声音** 开启本浏览器的提示音，默认关闭。
网页处于后台时，新消息会播放轻提示；在前台发出或收到番茄、便便时会播放短音效。
可单独调节音量，点击 **试听** 检查效果。
消息提醒和投掷音效都可选择本地音频，每个文件最多 256 KiB、3 秒；可分别试听或恢复内置音效。
自定义音效只保存在当前浏览器，不会发送给房间里的其他人。

在附件卡片上，普通文件点**下载**，图片点**下载原图**。Piik 会读取本机已有的副本，或从房间里提供原件的成员那里接收。
在支持此功能的桌面 App 里，保存后可点**在文件夹中显示**。

点缩略图可放大，再选**查看原图**可看完整分辨率或播放动图。卡片没有缩略图时，点**查看图片**可加载原图。
原件暂时无人提供时，已有的缩略图仍能打开，也可以请发送者上线或重新发送。
用户头像同样可以放大查看，按 Escape 或点关闭按钮回到房间。

观看画面时，播放栏的 **弹幕** 可显示该房间的新消息；在 **播放设置 → 弹幕** 中调整外观。
加载旧记录不会重播弹幕。系统视频全屏和视频画中画不显示弹幕。

## 房间语音

1. 在左下方个人区域点击 **加入语音**，按提示允许使用麦克风，无需房主先开启通话。
2. 使用常驻语音控件开关麦克风、暂停收听或 **退出语音**；在 **语音设置** 中选择输入设备、降噪与回声消除。

![房间聊天中的图片缩略图和聊天区下方已加入的语音控件。](../assets/guide/channel-room.zh-CN.png#gh-light-mode-only)
![房间聊天中的图片缩略图和聊天区下方已加入的语音控件。](../assets/guide/channel-room.zh-CN.dark.png#gh-dark-mode-only)

悬停在麦克风、耳机或某个人的扬声器按钮上可调节音量，触屏上可长按。
房间名左侧的小箭头可以收起或展开语音名单。
静音某个人只影响你听到的声音。麦克风和收听控件不改变分享画面的声音。
房间管理者还可在语音设置中调整 **房间语音码率**。
麦克风按钮里的绿色填充随你的声音变化；收到朋友的声音时，语音栏里人物的麦克风会亮起。
耳麦展开本身只表示已开麦。

可以同时加入多个房间的语音。加入多个房间后，用语音房间选择框确定正在操作哪个房间的
麦克风、收听和退出按钮。切换聊天房间或停止画面分享不会退出这些语音；结束时分别退出即可。

**Ctrl+Shift+M** 开关麦克风，**Ctrl+Shift+D** 开关收听；macOS 使用 **Command** 代替 Ctrl。
快捷键作用于语音栏当前选中的房间。在 **语音设置 → 键盘快捷键** 中可更改或清除组合，录制时按 Esc 取消。
页面或房间工具窗获得焦点时生效，输入文字和远程键盘控制优先。
连接支持此功能的 Windows App 后，可开启 **在其他应用中使用快捷键**；每行会显示该组合是否注册成功。

浏览器开麦需要安全环境，例如已接受的 HTTPS 或 localhost。
本地访问见 [App 使用参考](../../prototype/channel-server/README.md#local-app-link)，
平台要求见 [Native 媒体说明](../../prototype/channel-native/README.md)（英文）。

### 来源声音、分享麦克风与房间语音

- **来源声音** 来自分享的标签页、程序或屏幕，随画面播放控件调整。
- [**分享麦克风**](./sharing.zh-CN.md#分享麦克风)把你的讲解加入画面，观看者无需加入语音就能听到；停止该分享时结束。
- **房间语音** 是独立的聊天通话，单独加入，也有自己的收听控件。

同时开分享麦克风和房间语音，可能让朋友听到两次你的声音，保留需要的一路即可。
建议使用耳机；系统声音采集还可能再次采到浏览器正在播放的朋友声音。
相关操作见[分享声音设置](./sharing.zh-CN.md#分享屏幕时排除语音软件的声音)。

## 把房间放在画面或游戏旁

完整工作区里，点击沙发旁的 **弹出房间小窗**，直接把聊天、人物和语音控件移到置顶小窗。
其他浏览器使用页面内可移动的 **房间交流面板**。
保持原页面打开；关闭小窗，或再次点击同一个房间小窗按钮，会将控件和草稿收回页面。
极简分享中，**互动**先打开页面内面板，主沙发保持可见；再点面板的画中画按钮可移到小窗。

使用 Windows 版 Piik App 托管站点时，在 App 中加入语音，然后在语音控制区点击 **打开语音浮层**。
浮层置顶显示谁在说话，鼠标点击会穿过浮层，落到下方的应用。
回到 Piik 点击 **调整语音浮层**，即可拖动浮层或调整大小，再点击 **固定语音浮层** 或按 Esc。
固定后可用 Piik 语音控制区里的 **收起** 关闭浮层。调整时也可用标题栏上的关闭按钮。

关闭房间小窗或语音浮层后，语音通话会继续。游戏使用窗口或无边框模式时更方便查看，独占全屏可能遮住窗口。

## 让朋友操作共享的电脑

通过 App 分享窗口或屏幕，在该分享上开启 **远程控制**，再允许朋友的请求。
获准进入房间不等于获准控制电脑。观看者从对应画面的播放栏申请控制，结束时点击 **结束控制**；
分享者也可撤回许可或停止该分享。

支持哪些电脑、双方如何操作，见[远程控制与多人同乐](./remote-control.zh-CN.md)。
