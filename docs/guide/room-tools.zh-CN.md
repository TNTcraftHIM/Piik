# 聊天、语音与远程控制

本页适用于 3.0 内测版；正式版请看 [2.6.0 指南](https://github.com/TNTcraftHIM/Piik/blob/v2.6.0/docs/guide/room-tools.zh-CN.md)。

[English](./room-tools.md) · 简体中文 · [文档中心](./README.zh-CN.md)

一个域里可以有多个房间。在侧栏选择房间后，就能阅读该房间的聊天。
获准进入房间的人都可以聊天、加入语音、分享画面或观看别人的分享。
域主和房主分别管理域和房间设置，日常参与不需要额外的身份组。

## 聊天与表情

1. 选择房间，在聊天输入框中发送消息。点击附件按钮可添加图片或文件，也可以同时附上文字。
2. 点击消息旁的 **回应这条消息**，添加表情；再次点击自己选中的表情即可移除。
3. 点击 **更早的消息** 向前阅读；**最新消息** 可回到当前聊天。

确认发送的消息和消息表情由托管房间的一端保存。刷新页面或重新进入时，
房间托管端在线即可重新载入历史。聊天与历史通过域连接传送，不必等待 P2P 连通；
域会转发聊天正文，但不保存房间历史。附件记录保留在聊天中，不代表文件始终在线；
有参与者持有可读取的副本时，才能打开或下载。

点击房间里的人物可以打开互动菜单。人物表情与投掷道具是实时效果，不会保存为消息表情。

文件内容、语音和共享画面使用各自的 P2P 连接。

观看画面时，播放栏的 **弹幕** 可显示该房间的新消息；在 **播放设置 → 弹幕** 中调整外观。
加载旧记录不会重播弹幕。系统视频全屏和视频画中画不显示弹幕。

## 房间语音

1. 在所选房间顶部点击 **加入语音**，按提示允许使用麦克风，无需房主先开启通话。
2. 只想听时，打开 **加入语音** 旁的箭头，选择 **只收听，不开麦**。
3. 使用常驻语音控件开关麦克风、暂停收听或 **退出语音**；在 **语音设置** 中选择输入设备、降噪与回声消除。

悬停在麦克风、耳机或某个人的扬声器按钮上可调节音量，触屏上可长按。
静音某个人只影响你听到的声音。麦克风和收听控件不改变分享画面的声音。
房间管理者还可在语音设置中调整 **房间语音码率**。

可以同时加入多个房间的语音。加入多个房间后，用语音房间选择框确定正在操作哪个房间的
麦克风、收听和退出按钮。切换聊天房间或停止画面分享不会退出这些语音；结束时分别退出即可。

浏览器开麦需要安全环境，例如已接受的 HTTPS 或 localhost。
本地访问见 [App 使用参考](../../prototype/channel-server/README.md#local-app-link)，
平台要求见 [Native 媒体说明](../../prototype/channel-native/README.md)（英文）。

### 来源声音、分享麦克风与房间语音

- **来源声音** 来自分享的标签页、程序或屏幕，随画面播放控件调整。
- **分享麦克风** 把你的讲解加入画面，观看者无需加入语音就能听到；停止该分享时结束。
- **房间语音** 是独立的聊天通话，单独加入，也有自己的收听控件。

同时开分享麦克风和房间语音，可能让朋友听到两次你的声音，保留需要的一路即可。
建议使用耳机；系统声音采集还可能再次采到浏览器正在播放的朋友声音。
相关操作见[分享声音设置](./sharing.zh-CN.md#分享屏幕时排除语音软件的声音)。

## 把房间放在画面或游戏旁

点击房间顶部的 **小窗**，把聊天、人物和语音控件移到可移动的房间小窗。
支持的桌面浏览器可通过 **在置顶窗口中打开** 将它弹出。
保持原页面打开，关闭小窗会将控件收回页面。

打开或关闭小窗不会加入或退出语音。游戏使用窗口或无边框模式时更方便查看，独占全屏可能遮住小窗。

## 让朋友操作共享的电脑

通过 App 分享窗口或屏幕，在该分享上开启 **远程控制**，再允许朋友的请求。
获准进入房间不等于获准控制电脑。观看者从对应画面的播放栏申请控制，结束时点击 **结束控制**；
分享者也可撤回许可或停止该分享。

平台要求见 [Native 输入说明](../../prototype/channel-native/README.md)（英文）。每个人的分享分别授权。
