# 进房后没画面

<a id="进房后没画面没有可用的媒体线路"></a>

## 提示「没有可用的媒体线路」

先请房主看一眼自己的分享预览。

- **房主也看不到画面。** 请房主重新分享一个打开的窗口，例如浏览器窗口。预览里出现画面后，朋友再打开邀请。[开始分享](./sharing.zh-CN.md#开始分享)
- **房主看得到画面。** 问问其他观众能不能看，然后选择下面对应的情况：[只有我没画面](#只有我没画面其他人能看) · [所有人都没画面](#所有人都没画面)。

## 只有我没画面，其他人能看

- **换个浏览器。** 用另一款浏览器打开同一邀请。如果能播放，可以直接在那里看。[原浏览器的连接设置](./network.zh-CN.md#浏览器限制了-webrtc)
- **换个网络。** 用手机流量或热点打开同一个**公网邀请**。如果能播放，可以用这个网络继续看。
- **只有后进房的人看不到。** 请一位能看的朋友保持房间打开。如果这位朋友的**本机转发上限**是 **0**，请他在 **播放设置 → 连接** 里调高上限。后进房的观众再刷新页面。[设置转发人数](./sharing.zh-CN.md#连接偏好)

## 所有人都没画面

- **房主预览正常，朋友都看不到。** 大家可以[加入同一个虚拟局域网](./network.zh-CN.md#可选虚拟局域网)。房主在组网工具里查看自己这台设备的 IPv4 地址，再打开 Piik App 的 **本地房间 → 局域网邀请地址**，在列表里选中同一个地址。开始分享后，把新生成的完整邀请链接发给朋友。
- **有支持服务器转发的站点。** 请管理员确认站点已启用媒体转发（SFU）。房主在该站点关闭 **隐私模式** 后开播，发送该站点生成的新邀请。Piik 会在直连失败时尝试服务器转发。[用 App 在已有站点分享](./getting-started.zh-CN.md#通过已有站点使用-app)
