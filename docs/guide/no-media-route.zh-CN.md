# 进房后没画面（没有可用的媒体线路）

你已经进了房间，画面和声音还没传到你的设备。刷新一次可以重新连接。如果仍然没有画面，可以直接和朋友[用虚拟局域网组网](./network.zh-CN.md#可选虚拟局域网)，也可以按你们看到的情况选择办法。

## 只有我没画面，其他人能看

用手机流量或热点打开同一个**公网邀请**。如果这样能看到画面，可以用这个网络继续看。

如果是后加入的人看不到，请能看的朋友保持房间打开。如果他的**本机转发上限**设为 **0**，可以在 **播放设置 → 连接** 调高上限，让 Piik 尝试经由他转发。[转发人数设置](./sharing.zh-CN.md#连接偏好)

## 所有人都没画面

- **房主的预览也是黑的，或分享已停止。** 房主重新选一个普通窗口，点击 **开始分享**，确认自己的预览中出现了窗口内容。[选来源与开播](./sharing.zh-CN.md#开始分享)
- **房主预览正常。** 可以让一位使用其他网络的朋友加入。如果他能看到画面，请他保持房间打开，让其他观众重试。也可以直接组一个虚拟局域网。大家加入同一个虚拟网络，房主在 App 选择 **本地房间 → 局域网邀请地址**，选组网工具分配的地址，开播后把新邀请发给朋友。[虚拟局域网图解](./network.zh-CN.md#可选虚拟局域网)
- **有支持服务器转发的站点。** 请管理员启用媒体转发（SFU）。房主在该站点关闭 **隐私模式** 后开播，发送该站点生成的新邀请。Piik 会在直连失败时尝试服务器转发。[用 App 在已有站点分享](./getting-started.zh-CN.md#通过已有站点使用-app)

App 的公网邀请负责让朋友打开房间网页。用 App 公网邀请或 Piik 在线版观看时，画面由房主或其他观众发送。
