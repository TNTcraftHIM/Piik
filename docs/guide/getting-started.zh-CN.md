# 第一次用 Piik

[English](./getting-started.md) · 简体中文 · [文档中心](./README.zh-CN.md)

本指南适用于提供给测试者的 **3.0 内测 App 和 3.0 链接**。
公开在线版与正式下载仍属于 2.x；使用这些版本时，请看
[正式版文档](https://piik.tv/docs/zh/)。

| 你已经有… | 从这里开始 |
| --- | --- |
| 朋友的 3.0 链接 | [加入对方的房间](#加入朋友的房间)，用浏览器就能观看。 |
| 收到的 3.0 内测 App | [用 App 创建房间](#用-piik-app-分享)。 |
| 群组的 3.0 站点地址 | [在群组的站点加入房间](#使用已有站点分享)。 |

一个**站点**可以有多个房间。站点所有者决定谁能建房，也可以要求成员创建的房间仅凭邀请加入。进房后，你可以打字聊天、加入语音、分享自己的屏幕，或看朋友的画面。

## 加入朋友的房间

1. 用电脑或手机浏览器打开完整的 3.0 链接。站点会直接打开，并在当前浏览器中记住你的身份。
2. 从房间列表选择房间。窄屏上点击**房间**可打开列表。
   私密房间可能还需要专属邀请或**房间密码**。
3. 在房间的可观看画面中，找到想看的朋友并点击**观看**。
   浏览器未自动播放时，点击**播放**。
4. 在消息框输入文字聊天。在个人区域点击**加入语音**，按提示允许使用麦克风。
   只想收听时，关闭自己的麦克风即可。

多人可以同时分享，由你选择观看哪些画面。播放音量与本地暂停只改变你的观看。
将鼠标移到画面上、轻点画面，或用键盘聚焦播放按钮，即可显示控制栏。

看朋友的分享不需要先启动自己的 App 或另建房间。请保留对方的完整链接；
打开自己的 App 会进入另一个站点。

## 免安装使用 3.0 链接

打开朋友的 3.0 链接或你们提供的 3.0 站点，再按[加入房间](#加入朋友的房间)操作。
浏览器支持时，也能直接分享屏幕或摄像头。`demo.piik.tv` 是公开 2.x 站点，
不是本次内测的入口。

## 用 Piik App 分享

1. 使用**收到的 3.0 内测程序包**。Windows 完整解压后打开 `piik-app.exe`；
   Android 安装提供的 APK，再打开 Piik。桌面程序包内的文件应保持在一起。
2. Windows 默认在 Piik 窗口中打开启动页，也支持使用系统浏览器。按下方说明选择模式，再点击**进入 Piik**。
   首次进入会显示房间总览。以后可以点 Piik 标志返回总览。
3. 如果站点允许你建房，且还没有房间，点击**创建第一间房间**。默认名称**客厅**可以修改。
   如果表单提供选项，可选择**公开**或**私密**。
   核对托管提示，再点击**创建房间**，即可进入。以后从房间列表的**创建房间**
   打开同一表单；窄屏先点**房间列表**。
4. [邀请朋友](#邀请朋友)后，点击**开始分享**，选择**浏览器**、**摄像头**，
   或 App 提供的窗口／屏幕来源。选定实际画面，需要且支持时开启来源声音。
5. 朋友进入房间后，在你的画面旁点击**观看**。
   每个人单独加入语音；分享画面不会自动开启通话。

### 选择 App 模式

- **局域网使用：** 适合处于同一局域网或虚拟局域网的朋友。
  出现多个邀请地址时，选择对方能访问的网卡地址。
- **公网邀请：** 适合其他网络的朋友。**自动生成**会在 App 运行期间提供临时
  Cloudflare 地址，地址变化后需发送新的链接；**使用已有地址**可接入[自管 HTTPS 代理](#使用已有公网地址)。

局域网邀请使用 HTTPS。启动**局域网使用**后，返回 App 启动页，展开**进入 Piik**下方的
**局域网连接详情**，查看网址与证书指纹。首次接受警告前，先与浏览器显示的证书核对，
操作见[证书确认说明](./troubleshooting.zh-CN.md#本地-https-证书提示)。

### 使用已有公网地址

如果你已经配置了 frp 或其他 HTTPS 反向代理：

1. 启动站点前，选择**公网邀请 → 使用已有地址**，填写不含路径、查询参数或邀请片段的 HTTPS 站点地址。
2. 将站点的 HTTP 和 WebSocket 请求转发到页面显示的**本机转发目标**，初始为
   `http://127.0.0.1:8787`。frpc 与 App 运行在同一台电脑上；不要转发独立的 App 管理／发现端口。
3. 在代理侧配置域名和受信任的证书，可参考 [frp HTTPS 转 HTTP 示例](https://gofrp.org/en/docs/examples/https2http/)。
   保持 App 和代理运行，再从房间界面复制邀请链接。

修改**站点端口**后，也要同步更新代理目标。这个配置提供站点和聊天连接；画面、语音和点对点
文件传输仍需要各自的[连接](./network.zh-CN.md)，这个 HTTP 隧道不提供这些传输路径。

### 邀请朋友

- **进入站点：** 发送站点地址，朋友打开后就能选择公开房间。
- **进入公开房间：** 点击房间标题旁的邀请按钮，再**复制房间链接**。
- **进入私密房间：** 房主在同一位置**复制免密邀请**；还没有邀请时，点击**生成免密邀请**。
  设置了密码的房间也可以选择**需密码链接**，把房间链接发给朋友，再单独告知密码。
  复制操作下方的二维码使用同一个链接。

请只把私密房间邀请发给你想接纳进这个房间的人。
需要换新链接时，展开**重置房间邀请**，再点**确认重置邀请**：旧免密链接会失效，已获准的用户仍保留访问，密码不变。

### 通过已有站点使用 App

1. 保持 3.0 App 运行，在浏览器打开你们的 **3.0** 站点。
2. 点击 **App → 打开 App 页面**。浏览器询问本地网络权限时，请允许访问。
   在本机确认页核对站点网址，再点击**允许使用**。
3. 返回站点。轻量频道中，创建房间时已连接 App 就由 App 托管，否则由当前网页托管。托管频道中，服务器会管理房间，你离开后其他人仍可使用。创建表单会显示托管方式。
4. 进入房间后，**开始分享**中也会显示设备支持的 App 来源。

连接 App 可使用受支持的设备功能。已有房间继续由原托管端提供服务。已授权站点可在 App 启动页管理，
细节见 [App 使用参考](../../prototype/channel-server/README.md#local-app-link)。

### 版本升级

先阅读 3.0 内测包附带的升级说明；没有另行要求时，沿用原数据目录，更新 App 后刷新所用网页。
提示 `unsupported_storage_version` 或 `unsupported_domain_checkpoint` 时，按
[内测数据重置步骤](./troubleshooting.zh-CN.md#内测-app-提示-unsupportedstorageversion)重新开始。
公开的 2.x 下载不是本次 3.0 内测更新。

## 使用已有站点分享

打开群组提供的 3.0 站点地址或朋友发来的房间邀请，选择一个你能进入的房间。如果站点允许你建房，也可以点击**创建房间**。
进房后，点击**开始分享**来分享自己的画面，或在朋友的画面旁点击**观看**。房间还没有直播时也可以聊天、加入语音。

浏览器访问屏幕／摄像头需要 HTTPS 或 localhost 地址。可选画面与声音取决于浏览器和系统。
浏览器采集不强制使用 App；需要设备支持的原生来源时，再[连接 App](#通过已有站点使用-app)。

## 离开或刷新时

- **停止分享**结束该分享，**停止观看**结束你的观看，**退出语音**结束你在该房间的通话。
- 关闭网页会结束它的个人分享、观看和语音。**App 托管房间**在 App 运行时继续服务；
  **网页托管房间**在托管网页关闭期间不可用。切换房间或收起侧栏不会停止其他房间的活动。
- 关闭 App 启动网页不会停止 App。停止 App 会结束由它运行的活动，并让它在各个已连接站点
  托管的房间暂时不可用；重新打开 App 后可再次托管。
- 已确认的聊天记录由房间托管端保存。刷新后，托管端可用时会重新加载历史，
  更早内容可点击**更早的消息**查看。未发送草稿不保留到刷新之后；
  重新打开网页或 App 也不会自动恢复采集和语音。
