# 第一次用 Silip

[English](./getting-started.md) · 简体中文 · [回到 Silip](../../README.zh-CN.md)

Silip 支持一位房主分享屏幕，最多 20 位受邀观众观看。先选适合你的入口：

| 你想做什么 | 从这里开始 |
| --- | --- |
| 看朋友的画面 | [打开对方的邀请](#加入朋友的房间)，不必安装。 |
| 分享给其他网络的朋友 | [Silip App → 公网邀请](#用-silip-app-分享)，保持 App 运行。 |
| 使用你们自己的站点 | [打开已有站点](#使用已有站点分享)，按需连接 App 采集。 |

![三个步骤：选择窗口、复制房间邀请、和朋友一起坐上沙发。](../assets/quickstart.svg)

## 加入朋友的房间

1. 用电脑或手机浏览器打开朋友发来的邀请链接。
2. 等待画面出现。如果浏览器没有自动播放，点击 **播放**。
3. 将鼠标移到画面上，或轻点画面，显示播放控制栏。

播放控制栏只改变你自己看到的画面和听到的声音。
全屏、画面显示与音量选项见[播放控制](./sharing.zh-CN.md#播放控制)。

只有四位房间号时，打开同一个 Silip 站点，选择 **加入房间**，按需输入站点口令或房间密码。
无法通过房间号加入，或旧链接失效时，请房主发送当前邀请。

## 用 Silip App 分享

1. 从 [GitHub Releases](https://github.com/P4-aaaul/Silip/releases) 下载以 **`silip-app`** 开头、
   对应平台的程序包，或[从源码构建](../../cmd/silip-app/DEVELOPMENT.md#run-from-source)。手机或平板安装 App。
   桌面端完整解压并保留目录结构。
2. Windows 打开 `silip-app.exe`，macOS 打开 `Silip App.app`，Linux 运行 `./silip-app`。
   手机或平板安装后打开 Silip。启动页会在系统浏览器里打开。
3. 邀请不在同一局域网的朋友时，选择 **公网邀请**，再点击 **进入 Silip**。
   其他模式的用途见下方说明。
4. 点击 **开始分享**，按可用选项选择 **浏览器**、**摄像头**、**程序 / 窗口** 或 **屏幕**，
   然后选定要分享的画面与声音。
5. 复制房间邀请发给朋友。分享期间保持 App 和分享标签页打开。

macOS 首次打开被拦截时，按 [Mac 打开说明](./troubleshooting.zh-CN.md#macos-提示已损坏或无法验证开发者)处理。

### 选择 App 模式

![App 模式选择：已选中公网邀请，也可以选择本地房间。](../assets/guide/app-modes.zh-CN.png#gh-light-mode-only)
![App 模式选择：已选中公网邀请，也可以选择本地房间。](../assets/guide/app-modes.zh-CN.dark.png#gh-dark-mode-only)

- **公网邀请：** 给异地朋友发一个临时网页链接。需要互联网连接，关闭 App 后链接失效。
- **本地房间：** 朋友在同一局域网或虚拟局域网，对方需要能连接到你的电脑。
  多网卡时，可展开 **局域网邀请地址**，选择朋友所在的网络。

本地房间和公网邀请可展开 **站点口令** 设置可选的访问口令。
本地邀请使用 HTTPS；首次访问时，先与房主的 App 终端核对本地证书，再继续进入，
操作见[证书确认说明](./troubleshooting.zh-CN.md#本地-https-证书提示)。

<details>
<summary>回到启动页或更换模式</summary>

房间服务启动后，点击网页右上角已就绪的 **App**，可回到启动页管理授权或重新进入房间；
App 终端也保留 **App 启动页** 地址。更换本地房间／公网邀请模式时，关闭并重新打开 App 后选择。
这会结束原有房间，公网邀请地址也会重新生成。

</details>

### 通过已有站点使用 App

1. 保持 Silip App 运行，在浏览器打开 Silip 站点。如果站点要求口令，先输入口令。
   App 启动页无需选择房间模式。
2. 点击站点顶部的 **App**。浏览器询问本地网络权限时，请允许访问。
   找到 App 后，点击 **打开 App 页面**。
3. 在本机确认页核对站点网址，点击 **允许使用**。
4. 返回站点，点击 **开始分享**，选择 **程序 / 窗口** 或 **屏幕**，
   选好来源后，将新房间的邀请链接发给朋友。

也可以在 **开始分享** 的选源窗口里点击 **连接 Silip App**，连接后列表会直接显示 App 来源。
连接失败时，App 按钮旁会提供 **重试** 和 **下载 App**；仍可继续使用浏览器分享和观看。

已授权站点与启动收藏可在[App 启动页管理](../../cmd/silip-app/README.zh-CN.md#已授权站点)。
画面连不上时，查看[网络排查指南](./network.zh-CN.md)。

### 版本升级

App 与站点需要使用同一大版本，**2.x 与 1.x 不能混用**。
替换 App 或更新已有站点时，按[升级步骤](../../cmd/silip-app/README.zh-CN.md#升级)操作。

## 使用已有站点分享

使用朋友或管理员提供的 HTTPS Silip 站点。自行搭建时，按[自部署指南](../operations/self-hosting.zh-CN.md)操作。

1. 打开 Silip 站点。如果站点设置了口令，先输入口令。
2. 点击 **开始分享**，选择 **浏览器** 后在浏览器弹窗里选择屏幕、窗口或标签页；
   浏览器支持时，电脑和手机也可选择 **摄像头**。如需来源声音且选择器提供该选项，启用音频。
3. 确认预览画面后，点击 **复制邀请链接** 发给朋友。
4. 保持分享标签页打开。需要时使用 **暂停分享**、**切换来源** 或 **停止分享**。

浏览器屏幕采集需要 HTTPS 站点或 `localhost`。
弹窗里有哪些画面和声音可选，取决于浏览器与操作系统。
拿到邀请链接的人可以进入这个房间，请把它发给你想邀请的人。

想在同一站点使用 App 采集，可按[通过已有站点使用 App](#通过已有站点使用-app)的步骤操作。
站点负责房间与邀请，App 提供原生采集。
如果管理员已启用 SFU 转发，房主可在开始分享前关闭 **隐私模式**，允许使用这条兜底线路。
