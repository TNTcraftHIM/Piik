# 第一次用 Piik

[English](./getting-started.md) · 简体中文 · [回到 Piik](../../README.zh-CN.md)

Piik 支持一位房主分享屏幕，最多 20 位受邀观众通过浏览器观看。
本指南介绍加入房间、使用在线版、使用 Piik App，以及通过已有站点分享的方法。

[加入房间](#加入朋友的房间) · [在线版](#使用在线版) ·
[Piik App](#用-piik-app-分享) · [已有站点](#使用已有站点分享) ·
[远程控制](#让朋友操作共享的电脑) · [聊天与表情](#聊天与表情) · [问题排查](#遇到问题了)

观众只需要浏览器和邀请链接。
分享画面推荐下载 Piik App，选择 **公网邀请**。
想免安装，可以打开[在线版](https://demo.piik.tv)，直接在浏览器里创建房间并分享。

## 加入朋友的房间

1. 用电脑或手机浏览器打开朋友发来的邀请链接。
2. 等待画面出现。如果浏览器没有自动播放，点击 **播放**。
3. 将鼠标移到画面上，或轻点画面，显示播放控制栏。

播放控制栏只改变你自己看到的画面和听到的声音。
点击播控栏的按钮可暂停或继续；电脑上双击画面可进入或退出全屏（浏览器支持时）。
手机上轻点画面唤出控制栏，再使用其中的按钮。Safari 的视频全屏可能使用系统播控。

<details>
<summary>播放按钮分别做什么？</summary>

| 按钮 | 作用 |
| --- | --- |
| **剧场模式** | 在浏览器标签页内展开画面。 |
| **全屏观看** | 将画面展开至全屏。 |
| **悬浮小窗** | 浏览器支持时，把视频放进独立小窗。 |
| **音量** | 支持增强时最高 200%，否则最高 100%；声音失真时调低一些。 |
| **播放设置** | **完整显示** 保留全部画面；**等比铺满** 会裁掉边缘；**拉伸铺满** 会改变比例。连接设置默认为 **自动**，可选线路取决于房主和站点。 |
| **横竖切换**（测试版） | 只在本机切换画面方向，无需打开设备自动旋转，也不改变分享源。 |

</details>

只有四位房间号时，打开同一个 Piik 站点，选择 **加入房间**。
你可能需要站点口令和房间密码。能否通过房间号加入由房主决定；
无法加入时，请朋友发邀请链接。

房主可关闭链接旁的 **免密邀请**，复制普通房间地址。访客打开地址后按站点和房间设置
验证口令或密码；仅限邀请的房间需保留凭证。这个开关不会撤销已发出的邀请。

旧链接失效了，就请房主重新发一份当前邀请。
App 的本地房间和临时公网邀请会随本次 App 退出而结束。

## 使用在线版

1. 在浏览器中打开 [demo.piik.tv](https://demo.piik.tv)。
2. 点击 **开始分享**，选择 **浏览器** 分享屏幕、窗口或标签页；也可在电脑或手机上选择
   **摄像头**（需浏览器支持访问）。如需来源声音且选择器提供该选项，启用音频。
3. 确认预览后，点击 **复制邀请链接**，用另一台设备打开，或发送给朋友。
4. 分享结束后，点击 **停止分享**。

在线版由项目提供，画面仅通过设备间直连（P2P）传输。
在受限网络下，可能出现页面能打开、画面无法连接的情况。

## 用 Piik App 分享

1. 从 [GitHub Releases](https://github.com/TNTcraftHIM/Piik/releases) 或
   [Gitee 镜像](https://gitee.com/TNTcraftHIM/Piik/releases)下载以 **`piik-app`** 开头、
   对应平台的压缩包，完整解压并保留目录结构。
2. Windows 打开 `piik-app.exe`，macOS 打开 `Piik App.app`，Linux 运行 `./piik-app`。
   启动页会在系统浏览器里打开。
3. 邀请不在同一局域网的朋友时，选择 **公网邀请**，再点击 **进入 Piik**。
   其他模式的用途见下表。
4. 点击 **开始分享**，按可用选项选择 **浏览器**、**摄像头**、**程序 / 窗口** 或 **屏幕**，
   然后选定要分享的画面与声音。
5. 复制房间邀请发给朋友。分享期间保持 App 和分享标签页打开。

点击启动页的更新按钮即可下载新版 App；下载慢或无法下载时，可使用下方的 **Gitee 备用下载**。
跨大版本更新会显示兼容性提醒，点击提醒可查看升级说明；替换 App 前，请先阅读。

| 文件名包含 | 适用平台 |
| --- | --- |
| `windows-amd64` | Windows x64 |
| `darwin-arm64` | Apple 芯片；原生采集需 macOS 13 及以上 |
| `darwin-amd64` | Intel Mac；原生采集需 macOS 13 及以上 |
| `linux-amd64` | Linux x64 |
| `linux-arm64` | Linux ARM64 |

目前主要测试 Windows 版 Piik App 和浏览器分享。macOS 和 Linux 版 Piik App 仍需更多实机测试，
欢迎有设备的朋友试用并[反馈问题](https://github.com/TNTcraftHIM/Piik/issues)。
Linux 原生采集还需要[系统组件](../../native/capture/linux/README.md)。
程序包与启动参数的细节见 [App 指南](../../cmd/piik-app/README.zh-CN.md)。

### 选择 App 模式

| 模式 | 什么时候用 | 需要知道 |
| --- | --- | --- |
| **本地房间** | 朋友和你在同一个局域网。 | 多网卡时展开「局域网邀请地址」，选择与朋友同一网络的网卡和 IP。对方需要能连接到你的电脑，可以设置本地站点口令。 |
| **公网邀请** | 朋友在别处，想临时发个邀请。 | 需要互联网连接；公网地址只在本次 App 运行期间有效。 |

本地房间和公网邀请可展开 **站点口令** 设置可选的访问口令。
房间服务启动后，点击网页右上角已就绪的 **App**，可回到启动页管理授权或重新进入房间；
App 终端也保留 **App 启动页** 地址。更换本地房间／公网邀请模式时，关闭并重新打开 App 后选择。
这会结束原有房间，公网邀请地址也会重新生成。

### 通过已有站点使用 App

1. 保持 Piik App 运行，在浏览器打开 Piik 站点。如果站点要求口令，先输入口令；
   项目提供的[在线版](https://demo.piik.tv)无需站点口令。App 启动页无需选择房间模式。
2. 点击站点顶部的 **App**。浏览器询问本地网络权限时，请允许访问。
3. 在本机确认页核对站点网址，点击 **允许使用**。
4. 返回站点，点击 **开始分享**，选择 **程序 / 窗口** 或 **屏幕**，
   选好来源后，将新房间的邀请链接发给朋友。

也可以在 **开始分享** 的选源窗口里点击 **连接 Piik App**，连接后列表会直接显示 App 来源。
连接失败时，App 按钮旁会提供 **重试** 和 **下载 App**；仍可继续使用浏览器分享和观看。

同一浏览器会记住这次连接。之后直接访问站点，点击 **开始分享**，
选择 **程序 / 窗口** 或 **屏幕**，即可使用正在运行的 App。
换浏览器、使用无痕窗口或清除站点数据后，重新连接即可；App 已允许的同一站点无需再次确认。
启动页显示已授权的站点，网址右侧的 **×** 可取消授权；允许新站点会替换旧站点，并结束旧站点的 App 连接。
点亮网址旁的 **☆**，下次启动 App 时就会直接打开该站点；取消星标后恢复打开启动页。
连接后，点击站点顶部的 **App** 可再次打开启动页，管理这些设置。
站点打不开时，可使用 App 终端中的 **App 启动页** 地址。
如要通过自己的 App 使用朋友的新公网邀请地址，需要重新连接并确认；App 保存的分享画质不受地址变化影响。

**网页能打开，不代表视频一定能连通。** 公网邀请为房间提供临时网页地址，
画面和声音仍靠参与者之间的连接传输。此模式没有媒体服务器兜底，
临时地址也不保证持续可用。所有模式都需要可用的 UDP 媒体路径。
具体连接方式见 [App 指南](../../cmd/piik-app/README.zh-CN.md#运行模式)。

### 版本升级

**Piik 2.x 与 1.x 不能混用。** App 与连接的站点需要使用同一大版本。
不同 2.x 版本保留已有的分享和观看功能；新功能需要相关 App 与站点支持。
升级前，请先查看 [GitHub](https://github.com/TNTcraftHIM/Piik/releases/latest) 或
[Gitee](https://gitee.com/TNTcraftHIM/Piik/releases) 上的版本说明。

- **本地房间或公网邀请：** 停止分享并关闭旧 App，完整解压新版程序包，
  启动后重新发送邀请链接。
- **已有站点：** 管理员先按[更新指南](../operations/service-management.zh-CN.md)升级 Server，
  然后更新连接该站点的 App，并刷新所有分享与观看页面。

重启 App 或 Server 会中断正在进行的分享。本次升级不变更房间数据库结构。

## 使用已有站点分享

需要先有一个运行 Piik Server 的 HTTPS 站点，可以使用朋友或管理员提供的地址。
也可以使用项目提供的[在线版](#使用在线版)或 [Piik App](#用-piik-app-分享)。
自建站点属于进阶操作，服务器、HTTPS 和网络端口的配置步骤见[部署指南](../operations/self-hosting.zh-CN.md)。

1. 打开 Piik 站点。如果站点设置了口令，先输入口令。
2. 点击 **开始分享**，选择 **浏览器** 后在浏览器弹窗里选择屏幕、窗口或标签页；
   浏览器支持时，电脑和手机也可选择 **摄像头**。如需来源声音且选择器提供该选项，启用音频。
3. 确认预览画面后，点击 **复制邀请链接** 发给朋友。
4. 保持分享标签页打开。需要时使用 **暂停分享**、**切换来源** 或 **停止分享**。

浏览器屏幕采集需要 HTTPS 站点或 `localhost`。
弹窗里有哪些画面和声音可选，取决于浏览器与操作系统。
拿到邀请链接的人可以进入这个房间，请把它发给你想邀请的人。

想在同一站点使用 App 采集，可按[通过已有站点使用 App](#通过已有站点使用-app)的步骤操作。
站点负责房间与邀请，App 提供原生采集。
如果管理员已启用 SFU 转发，房主可在开始分享前关闭 **隐私模式**，允许使用这条兜底线路。
项目提供的在线版仅使用 P2P。

## 画面与声音设置

在画面下方打开 **分享设置**，可直接选择画质预设；
展开 **画面细调**，再调整分辨率、帧率、码率、画面偏好和视频编码。

- 在 **画面细调** 的 **分辨率上限** 中填写宽和高。画面在上限内保留来源比例，
  包括竖屏和超宽屏。
- 滑块覆盖 15–60 帧（每步 5 帧）、2–12 Mbps（每步 0.5 Mbps）的常用范围；也可直接填写 1–240 帧的 **帧率上限**
  和 0.1–240 Mbps 的 **视频码率上限**。
  不在滑块档位上的数值显示为 **自定义**；点击 **返回常用范围**，使用最近的可用档位。
  帧率范围随画幅变化，例如可以请求 1080p240、1440p144 或 4K60。
- **声音** 下可调整来源声音和麦克风输入；**音频质量** 调整分享输出，
  可选择预设，也可填写 6–320 kbps 的 **音频码率上限**。

可选范围会随画幅和连接的 App 变化。实际画质和声音仍会根据来源、设备与可用带宽调整。

Piik 会记住已应用的设置，供下次使用。仅用浏览器时，设置保存在当前站点；
通过新版 App 打开时，更换公网邀请网址也能保留设置。

## 加上自己的声音

分享时，点击画面下方的 **麦克风**，并允许访问。
再次点击即可静音。在画面下方的 **分享设置 → 声音** 中可以选择麦克风和调节输入音量，默认 100%，最高可调至 200%。
观众会同时听到来源声音和你的解说；房主本机预览保持静音。

摄像头分享不会自动开启麦克风。App 的 **程序 / 窗口** 和 **屏幕** 采集也使用同一组控件，
可以保留「默认设备」，也可以指定麦克风。在 **摄像头** 页签中允许访问后，点击对应的画面卡片开始分享。
设备名称和可用预览取决于浏览器权限；正在分享摄像头时，其他摄像头只显示名称。
建议佩戴耳机，避免扬声器声音被麦克风再次收进去。

通过 **浏览器** 或 **摄像头** 分享时，声音设置中的 **降噪与回声消除** 默认开启，
由浏览器处理回声、杂音和音量。输入音乐或虚拟音频设备的声音时，可关闭它；
设备及系统自身的音效仍由各自设置控制。App 原生采集使用设备及系统的音频设置。

带麦克风的摄像头仍需分别选择画面和音频输入。OBS 虚拟摄像头只提供画面；
如需带上 OBS 的声音，可按 [OBS 音频转接教程](https://obsproject.com/kb/video-call-streaming-tutorial/)
设置虚拟音频设备，再在 Piik 的麦克风列表中选择对应输入并开启麦克风。

### 分享屏幕时排除语音软件的声音

在 Windows 上，此控件用于 **屏幕** 分享的系统声音。**程序 / 窗口** 只采集所选应用及其子进程的声音；
**摄像头** 的声音来自单独选择的麦克风或音频输入。

在支持此功能的 Windows App 中，打开 **屏幕** 页签并开启 **系统声音**，
在 **排除应用声音** 中选择语音软件的窗口，再选择要分享的屏幕。
未列出的应用请先打开窗口，再刷新。此功能排除所选进程及其子进程，
其他应用的声音仍会被分享，包括输出到其他播放设备的声音。
它不影响 Piik 麦克风，也不能消除扬声器被麦克风收音产生的回声。

使用虚拟麦克风时，如果关闭 Piik 麦克风后仍能听到你的声音，可暂时关闭 **系统声音** 对照。
若声音随之消失，请检查混音软件的播放输出与监听，或改为只分享目标应用的窗口音频。
排除语音软件不会同时排除另一个混音软件；后者输出到虚拟播放设备的声音也可能被采集。

开播后，可在 **分享设置 → 声音** 中调整系统声音和排除的应用，无需停止分享。
所选应用关闭或重启后，来源声音会停止；请刷新应用列表并重新选择。
暂时关闭来源声音会保留排除选择；需要恢复完整的系统声音时，选择 **不排除**。
此控件需要新版页面和通过进程排除能力检测的 Windows App，不适用于浏览器自带的分享选择器。
Windows 10 是否支持取决于系统更新与实际检测；未显示此选项时，可改为分享单个应用窗口，或将语音软件输出到另一播放设备。

## 让朋友操作共享的电脑

1. 通过 Piik App 的 **程序 / 窗口** 或 **屏幕** 开始分享。
2. 打开画面下方的 **远程控制** 并开启开关，默认使用 **每次询问**。
3. 朋友在播放控制栏中点击 **请求控制**。收到请求后，在自己的分享页面选择 **允许控制**。

分享窗口时，允许控制后请切回该窗口。其他窗口处于前台时，远程输入会暂停；切回即可继续。

同一时间只能有一位观众控制，可使用电脑或手机浏览器。更新房主的 App 和房间所在站点后，
观众刷新页面即可。房主开启远控、连接支持后，观众才会看到控制按钮。
浏览器和摄像头采集不支持接收远程操作。
观众需通过 HTTPS 或本机页面使用远控；普通局域网或虚拟 IP 的 HTTP 页面可以观看，
但没有远控所需的浏览器加密接口，因此不会出现控制按钮。

双方都可以点击 **结束控制**。房主还可以在本机按 **Ctrl+Alt+F10**（Windows）
或 **Control+Option+F10**（macOS）立即结束；如与其他应用冲突，可在房主的
**远程控制** 面板中更换功能键。快捷键保存在当前站点的浏览器存储中，各站点独立设置。
观众可以在 **远程键盘** 中单独调整
**退出控制快捷键**，独立键盘窗口也可使用。切换来源或停止分享会关闭远控；
连接中断后，观众需要重新请求。
授权方式会记住，但不会自动开启远控。上次选择 **房间观众** 时，再次开启会先展示
授权说明；点击 **允许观众控制** 后才生效。控制密码不会保存。

手机上滑动可移动鼠标，轻点点击、长按拖动；双指轻点右击、滑动滚动。
捏合可以放大画面，放大后用双指移动查看位置。**远程键盘** 提供按键、组合键和文字输入。
电脑上可开启 **游戏鼠标** 连续转动视角，按 **Esc** 释放鼠标。

<summary>授权与平台支持</summary>

**房间观众** 允许房间内的观众直接取得空闲控制权；**控制密码** 要求输入单独设置的控制密码。
这些设置只对当前分享来源有效。允许控制后，对方可以操作这台电脑的鼠标和键盘，
请只授权给信任的人；操作范围不受视频画面边界限制。

macOS 需要允许「辅助功能」权限。Linux 需要桌面环境支持 Portal，目前只支持控制所选屏幕，
不支持单个应用窗口。Windows 是主要经过实机验证的房主平台，macOS/Linux 的设备验收仍有限。
受系统保护的快捷键和部分游戏可能无法接收远程输入。

</details>

## 聊天与表情

房主创建房间后，参与者可以点击沙发下方的 **互动** 发送消息。
点击沙发上的人物可打开表情菜单：给自己发的表情出现在头顶，送给朋友的表情会飞向对方。
互动窗口可以移动和缩放，不会挤动页面。

支持的桌面浏览器会在窗口右上角显示 **在置顶窗口中打开**，方便玩游戏时看消息、接收表情，
也可以在小窗中选人互动。保持 Piik 页面打开；关闭小窗会将它收回页面。建议游戏使用窗口或无边框模式，
独占全屏不保证显示置顶窗。小窗目前不支持透出游戏画面或鼠标穿透。

输入框旁和观众播放控制栏中的 **弹幕** 可以把新消息显示在画面上，默认关闭，只影响自己的观看。
通过 **播放设置 → 弹幕** 或聊天窗口中的 **聊天设置** 调整字号和不透明度，两处共用本机设置。
系统视频全屏和画中画无法显示弹幕。

停止分享后仍可继续聊天；App 的本地房间和公网邀请需要保持 App 运行。
每个页面只保留本页最近收到的消息，刷新后清空，后来加入的人看不到此前的记录。
需要留存时，可通过 **聊天设置 → 导出聊天记录** 将本页保留的最近消息（最多 1,000 条）保存为文本文件。
聊天消息经过房间所在的服务器，**不提供端到端加密**。

### 测试版房间语音

房主可先点击 **创建房间**、复制邀请，不必立即开播。
打开 **互动 → 语音**，点击 **开启房间语音**，房间成员即可自行 **加入语音**，不需要再次审批。
加入不会打开麦克风；发言者仍需自己点击 **打开麦克风**，并允许浏览器访问。
**本地静音** 只改变你自己听到的声音。
加入后，底部工具栏提供麦克风、收听和退出按钮。
**暂停收听** 只暂停你这里的房间语音播放，麦克风、视频声音和语音转发不受影响。
语音页的 **麦克风设置** 可选择输入设备、调整音量，以及开关降噪与回声消除。

停止画面分享后仍可继续语音；关闭或弹出互动窗口也不会退出。
观众可点击 **退出语音**；房主点击 **关闭房间语音** 会结束所有人的语音。
重新开启后，观众仍需自行加入、开麦。
房主说话也使用这个房间麦克风，观众需加入语音才能收听。
来源声音继续跟随画面；房间语音优先保证实时交流，画面延迟时可能先听到说话声。
建议佩戴耳机；分享整个系统声音可能把收到的语音再次传出，支持的 App 采集路径可尝试
[排除应用声音](#分享屏幕时排除语音软件的声音)。

支持的测试站点还提供 **播放设置 → 连接 → 帮助更多观众转发**，
允许观众为本次访问提供更多上行带宽。它仍是普通 P2P 转发；请在连接稳定、上行有余量时开启。
房间语音和这个选项需要配套测试版 Server／网页，旧版公开站点不会出现。
异地网络与真实音频设备仍需内测验证。
