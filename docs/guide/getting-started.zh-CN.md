# 第一次用 Piik

[English](./getting-started.md) · 简体中文 · [文档中心](./README.zh-CN.md)

本指南适用于提供给测试者的 **3.0 内测 App 和 3.0 链接**。
公开在线版与正式下载仍属于 2.x；使用这些版本时，请看
[已发布的 2.6 指南](https://github.com/TNTcraftHIM/Piik/blob/v2.6.0/docs/guide/getting-started.zh-CN.md)。

| 你已经有… | 从这里开始 |
| --- | --- |
| 朋友的 3.0 链接 | [加入对方的房间](#加入朋友的房间)，用浏览器就能观看。 |
| 收到的 3.0 内测 App | [用 App 创建房间](#用-piik-app-分享)。 |
| 已有的 3.0 站点 | [进入该域后创建房间](#使用已有站点分享)，可由网页或 App 托管。 |

**域**是容纳你们各个房间的空间。同一房间里，每个人都可以聊天、加入语音、
分享自己的画面，并选择要观看的画面。

## 加入朋友的房间

1. 用电脑或手机浏览器打开完整的 3.0 链接。如有提示，输入**域口令**，
   或向朋友索取当前有效的域邀请。
2. 从房间列表选择房间。窄屏上点击**房间**可打开列表。
   私密房间可能还需要专属邀请或**房间密码**。
3. 在房间的可观看画面中，找到想看的朋友并点击**观看**。
   浏览器未自动播放时，点击**播放**。
4. 在消息框输入文字聊天。点击**加入语音**可通话，旁边的箭头也提供仅收听选项。
   选择发言时，按浏览器提示允许使用麦克风。

多人可以同时分享，由你选择观看哪些画面。播放音量与本地暂停只改变你的观看。
将鼠标移到画面上、轻点画面，或用键盘聚焦播放按钮，即可显示控制栏。

看朋友的分享不需要先启动自己的 App 或另建房间。请保留对方的完整链接；
打开自己的 App 会进入另一个域。

## 免安装使用 3.0 链接

打开朋友的 3.0 链接或你们提供的 3.0 站点，再按[加入房间](#加入朋友的房间)操作。
浏览器支持时，也能直接分享屏幕或摄像头。`demo.piik.tv` 是公开 2.x 站点，
不是本次内测的入口。

## 用 Piik App 分享

1. 使用**收到的 3.0 内测程序包**。Windows 完整解压后打开 `piik-app.exe`；
   Android 安装提供的 APK，再打开 Piik。桌面程序包内的文件应保持在一起。
2. 启动页会在系统浏览器中打开。按下方说明选择模式，再点击**进入 Piik**，
   即可看到域及其房间列表。
3. 点击**创建房间**，填写名称。第一个房间可选**公开**，让域内的人都能进入。
   核对托管提示，再点击**创建房间**。现在房间已经可用，可以先发一条消息试试。
4. [邀请朋友](#邀请朋友)后，点击**开始分享**，选择**浏览器**、**摄像头**，
   或 App 提供的窗口／屏幕来源。选定实际画面，需要且支持时开启来源声音。
5. 朋友进入房间后，在你的画面旁点击**观看**。
   每个人单独加入语音；分享画面不会自动开启通话。

### 选择 App 模式

- **局域网使用：** 适合处于同一局域网或虚拟局域网的朋友。
  出现多个邀请地址时，选择对方能访问的网卡地址。
- **公网邀请：** 适合其他网络的朋友。App 运行期间会提供临时公网地址，
  地址变化后需发送新的链接。

局域网邀请使用 HTTPS。首次接受证书提示前，请与 App 终端中的指纹核对，
操作见[证书确认说明](./troubleshooting.zh-CN.md#本地-https-证书提示)。
域主可在域名称旁的**域设置 → 编辑域设置**中选择**公开**或**私密**入口，并设置可选的域口令。

### 邀请朋友

- **邀请进入域：** 打开房间列表，公开域点击**复制域地址**，私密域点击**复制域邀请**，
  并告诉朋友要进入哪个房间。旁边的二维码按钮使用同一个链接。
- **邀请进入私密房间：** 房主打开**房间选项**，点击**复制邀请**或房间二维码按钮。
  还没有邀请时，点击**生成新邀请**。该邀请可让接收者进入域及指定的私密房间。

请只把邀请发给你想接纳的人。进入域与进入私密房间是两回事：域邀请不会解锁所有私密房间。
需要换新链接时才使用**重置房间邀请**：旧链接会失效，已获准的用户仍保留访问。
旧邀请无法取回时，面板会先说明，再由你决定是否生成新邀请。

### 通过已有站点使用 App

1. 保持 3.0 App 运行，在浏览器打开你们的 **3.0** 站点。
2. 点击 **App → 打开 App 页面**。浏览器询问本地网络权限时，请允许访问。
   在本机确认页核对站点网址，再点击**允许使用**。
3. 返回站点。希望由 App 托管时，请**先连接 App，再创建房间**；
   创建表单会说明当前由谁托管。
4. 进入房间后，**开始分享**中也会显示设备支持的 App 来源。

连接 App 后，已有网页托管房间仍由原网页托管。已授权站点可在 App 启动页管理，
细节见 [App 使用参考](../../prototype/channel-server/README.md#local-app-link)。

### 版本升级

使用提供给你的 3.0 内测更新，并保留已有 App 数据。更新 App 后刷新所用网页；
如果 App 连接提示接口不兼容，按更新提示处理。公开的 2.x 下载不是本次 3.0 内测更新。

## 使用已有站点分享

打开你们的 3.0 地址或邀请，进入域后点击**创建房间**，或选择一个你能进入的房间。
然后按[上方房间与分享步骤](#用-piik-app-分享)从第 3 步继续。
即使还没人分享画面，也可以聊天和加入语音。

浏览器访问屏幕／摄像头需要 HTTPS 或 localhost 地址。可选画面与声音取决于浏览器和系统。
浏览器采集不强制使用 App；需要设备支持的原生来源时，再[连接 App](#通过已有站点使用-app)。

## 离开或刷新时

- **停止分享**结束该分享，**停止观看**结束你的观看，**退出语音**结束你在该房间的通话。
- 关闭网页会结束它的个人分享、观看和语音。**App 托管房间**在 App 运行时继续服务；
  **网页托管房间**在托管网页关闭期间不可用。切换房间或开关**分享视图**不会停止其他房间的活动。
- 已确认的聊天记录由房间托管端保存。刷新后，托管端可用时会重新加载历史，
  更早内容可点击**更早的消息**查看。未发送草稿不保留到刷新之后；
  重新打开网页或 App 也不会自动恢复采集和语音。
