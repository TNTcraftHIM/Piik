## Preparation: accepted direction and remaining decisions

**Take parallel observations and one RTC as the experiment direction.** We are
isolating the parallel local surveys with the three destinations still queried
in order. Offer/Answer secrecy and validation remain unchanged. The existing
socket-adoption proof now includes a real kernel stable-mapping/APDF case, with
both payload directions, fixed identity/deadline and stale-port cleanup. It has
not established relay-to-direct media migration or sequential-NAT success.

**Defer the GCD classifier default and the 64-gap threshold.** The wire owns
absolute step <=16 and the existing predicted targets, but 64 is new. Observed
spacings s*m and s*n yield s*gcd(m,n), which can overestimate the underlying step.
The bounded offline controls show both useful recovery and false classes. A
false Sequential beside Stable also replaces a working random-search choice.
The next comparison uses actual target/socket budgets, not classification rate
alone. No new threshold has been written into product.

**The exact early-stop predicate has an SDK gap.** Pinned str0m exposes selected
addresses/protocol but drops candidate kinds; Rtc's ICE agent is private. A local
TURN allocation is known, but missing remote provenance cannot prove directness
when a peer-reflexive pair wins before its trickle arrives. Native peers sharing
an immutable STUN-only configuration cannot create TURN candidates. Where TURN
is enabled and provenance is unknown, letting preparation run to its existing
five-second end is the simple conservative alternative. Do you accept that
bounded unknown result, or do you require a public selected-kind API before the
production change? A new two-end boolean would itself need path correlation.

The atomic Core/Driver migration must also remove the current deferral of normal
SDP while Required and keep a preparation queue failure from calling the pair's
ordinary fail path. Optional preparation cannot kill a healthy engine. Existing
Core admission and Native connecting deadlines keep their own owners; neither
is rearmed by the extra candidate. We are not changing those contracts piecemeal.
