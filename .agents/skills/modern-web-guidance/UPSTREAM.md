Retained: task-specific guide lookup, native platform primitives, explicit
browser-support reasoning and verification of the complete interaction.
The dialog, size-aware styling and content-first guides were read when reviewing
the integration; other guides remain available on demand at the source link.

Not adopted: mandatory execution before every frontend edit, `@latest` tool
installation on each use, broad prerequisite approval requests, mandatory
response headings/quotes, fixed layout percentages and unconditional adoption
of newly shipped APIs. Project policy and user decisions keep their authority.
No Chrome-extension workflow, automated code scanner, hook or extra application
dependency is installed. The large guide corpus is linked rather than vendored.
